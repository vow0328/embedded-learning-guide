# 11. 工具、仪器与仿真

**这一章是工具书，不是教程。用到的时候回来查，不需要通读。**

但有一句话值得放在最前面：**会不会用仪器，是嵌入式工程师"靠猜"和"靠证据"的分界线。**

一个逻辑分析仪抓到的波形，比盯着代码看半小时有用得多。很多"代码看着没问题、就是跑不起来"的情况，用仪器一看就能定位到是起始位错了、应答位没收到、还是时钟频率不对。

## 适合谁

所有人。这一章的价值不在"读完"，而在"用的时候知道有这个东西"。

## 应该先买什么

如果预算有限，按这个优先级买：

**顺序是：万用表 → 逻辑分析仪 → 调试器（ST-Link / DAP-Link）→ 可调限流电源 → 示波器。** 前两件加起来不到一百块，却能解决绝大多数问题；示波器价格跳一个量级，留到真的需要看波形时再买——到那时候你也更清楚自己需要多少带宽、多少通道。**理由、价格量级和取舍见 [11.1 测量仪器](01-测量仪器.md) 的"预算有限，先买哪个"。**

**注意：逻辑分析仪和示波器不能互相替代。**

- 逻辑分析仪只能看高低电平（数字信号），但通道多、能自动解码协议 → 查串口/I2C/SPI 时序用它
- 示波器能看真实电压波形（模拟信号），但通道少 → 查电源纹波、信号完整性、电机电流波形用它

## 关于仿真

仿真在嵌入式学习里是最被忽视、实际价值又很高的一块。

**它的价值不是替代实物，而是把"上硬件才能发现的问题"提前到电脑上发现。** 比如调 PID 时，"改一个参数、烧一次板、看一次现象"是极其低效的循环；而在 Simulink 里你可以直接观察阶跃响应、超调量、调节时间，在真正上板之前心里就有数了。

**但要记住仿真的边界**：真实系统里还有噪声、延时、量化误差、参数漂移、摩擦、饱和、死区等非理想因素。仿真的作用是**缩小排错范围**，不是给出最终答案。怎么仿真、哪些量值得看、什么时候必须实测，[11.3 电路与系统仿真](03-电路与系统仿真.md) 里逐条讲，这里不重复。
