# 8. 嵌入式 Linux

**这是一个独立且庞大的知识体系，和前面所有内容可以说是天差地别。**

RTOS 更像是"给单片机加了一个高级的任务调度器"，而 Linux 是完整的通用操作系统——进程管理、虚拟内存、文件系统、权限管理、网络协议栈、驱动模型，一整套都要从头学起。除了通用的进程与线程思维可以复用，几乎一切都要重新开始。

**所以这一章的第一条建议是：一定要按路线走，不要一上来就冲着点灯去。**

很多单片机背景的人在这里踩的坑完全一样：以为"嵌入式 Linux"也应该像学 STM32 那样，一上来就接板子、点灯、驱动外设。但实际情况恰恰相反——**在嵌入式 Linux 的前期学习阶段，甚至可以完全没有硬件实物参与**，一台电脑加一个 Ubuntu 虚拟机或 WSL 环境，就足够把最关键的基础学起来。

点灯这件事，在 Linux 学习里往往已经是学到中期、开始接触驱动和设备树之后才做的。

## 适合谁

- **Linux 方向**：全章必读，这是主线。
- **机器人/边缘计算方向**：8.1、8.2 必读，8.5、8.6 强烈建议。
- **纯 MCU 方向**：可以暂时跳过整章。但请知道——现在很多系统是"Linux 负责感知与决策、MCU 负责实时控制"的异构结构，不懂 Linux 会限制你参与完整系统的能力。

## 通读顺序建议

```
8.1 学习路线与环境（先装个 Ubuntu/WSL，把命令行用熟）
      ↓
8.2 应用层开发  ← 大部分人第一份 Linux 工作的核心内容
      ↓
8.3 驱动开发
      ↓
8.4 系统移植与构建
      ↓
8.5 实时 Linux  →  8.6 视觉与多媒体
```

**强烈建议不要跳步。** 从 Keil、CubeMX 这种图形化工作流切到命令行、交叉编译、Makefile、SSH、GDB，本身就有适应期。再叠加 U-Boot、内核配置、设备树同时劝退，很容易从入门到放弃。**先会用，再会改，最后再考虑从零搭建。**
