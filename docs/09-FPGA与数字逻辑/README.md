# 9. FPGA 与数字逻辑

**这是一门思维方式完全不同的技术。软件是"一条指令一条指令地顺序执行"，FPGA 是"所有逻辑同时工作"。**

FPGA（现场可编程门阵列）的本质是用可编程的逻辑单元搭出真实的数字电路。你写的不是"程序"，而是**电路的连接方式**。所以它没有"执行时间"的概念，只有"信号传播延迟"——这个区别决定了设计方法、调试方法都和写软件完全不同。

**为什么嵌入式的人要了解 FPGA**：现在很多系统采用"ARM 负责逻辑与通信、FPGA 负责高速实时处理"的异构架构，两者通过 AXI 总线协同。懂一点 FPGA 的嵌入式工程师，在这类系统里非常吃香。

## 入门 FPGA 的硬件门槛

FPGA 方向对装备的要求比单片机高：

- **开发板**：建议入门选 Xilinx（Vivado）或 Altera/Intel（Quartus）两大平台的板子，生态和资料最全，入门教学板价格量级在几百到一千多元，低端板一两百元也能起步。国产 FPGA（紫光同创、安路等）也在快速发展，国产替代方向可以考虑，但入门资料相对少。
- **仿真工具**：ModelSim 或 Vivado 自带的仿真器，前期绝大部分时间是在仿真里度过的。
- **示波器/逻辑分析仪**：验证实际信号时会用到。

## 一个常见误区

**不要把 Verilog 当 C 语言写。**

初学者最容易犯的错误是用"顺序思维"写 HDL：想着"先做 A，再做 B"，写出大量本可以并行、却被串行化的逻辑。结果就是资源占用高、时序跑不上去。

正确的思维是：**描述电路的结构和信号之间的连接关系，让所有该并行的逻辑真正并行**。这个思维转变通常需要几周时间，而且是学 FPGA 最难跨过的一道坎。
