# 1. 编程与软件基础

**这是全教程的地基。它看起来最不"嵌入式"，但决定了你能走多远。**

第 1 章的内容在应聘任何嵌入式岗位时都是隐性的加分项——面试官不会专门问你"内存分几段"，但会在你答不上来的时候，判断出你没有系统学过。反之，一个 C 语言和内存布局扎实的人，学任何一款新 MCU 都只是几天的事。

| 篇目 | 内容 | 难度 |
|---|---|---|
| [1.1 C 语言（嵌入式视角）](01-C语言（嵌入式视角）.md) | 指针与多级指针、位操作、函数指针与回调、`volatile`/`const`/`static` 的真实含义、变量住在哪个段（`.text`/`.data`/`.bss`/栈/堆）、内存对齐与大小端 | ★★ |
| [1.2 数据结构与算法](02-数据结构与算法.md) | 环形缓冲区、队列、栈、静态节点池、查找表各自解决什么问题，以及它们在本教程哪几篇展开 | ★ |
| [1.3 计算机组成与操作系统原理](03-计算机组成与操作系统原理.md) | 总线与中断、操作系统提供的四种抽象、调度、同步与死锁、优先级反转 | ★ |

**这一章只有 1.1 需要坐下来精读。** 1.2 和 1.3 是**定位篇**：它们讲的是数据结构与算法、计算机组成原理、操作系统这三门课在嵌入式里各自管什么、你实际会用到哪一部分、用到的时候去本教程哪几篇找答案——**它们不替代教材，读法是各花十几分钟过一遍，知道有这些概念、知道在哪展开，就够往下走了。** 真到要用的时候再回教材里补，那是 [13.3 资源地图](../13-学习路线与项目实战/03-资源地图.md) 里《书籍的定位：用到再翻》讲的事。

## 适合谁

- **零基础**：先按 [1.1 篇头](01-C语言（嵌入式视角）.md) 的自检清单把 C 语言语法补上（去哪补，那篇里写了），再回来读 1.1；1.2 和 1.3 可以边做项目边看。
- **转行程序员**：重点看 **1.1**，这是最容易缺的一环；1.2 和 1.3 快速过一遍，主要是把"这个词在本教程哪一篇"对上号。
- **在职补短板**：1.1 大概率有你没系统学过的地方；1.2 和 1.3 给出的落点清单比概念本身更值得看。

## 通读顺序建议

```
1.1 C 语言（精读）
      ↓
1.2 数据结构与算法（定位，十几分钟）
      ↓
1.3 计算机组成与操作系统原理（定位，十几分钟）
      ↓
第 2 章 MCU 与体系结构
```

**1.1 是全章最重要的一篇。** 如果你的时间只够读一篇，读它。

1.2 和 1.3 不必等全部读懂再往下走——它们的作用是**先让你知道有这些概念、遇到问题时该往哪一篇翻**。带着 [2.3 通用外设](../02-MCU与体系结构/03-通用外设.md) 里那个串口收数据的真实问题回头再读 1.2 的环形缓冲区那一段，比现在硬记有用得多。
