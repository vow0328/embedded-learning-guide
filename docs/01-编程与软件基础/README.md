# 1. 编程与软件基础

**这是全教程的地基。它看起来最不"嵌入式"，但决定了你能走多远。**

第 1 章的内容在应聘任何嵌入式岗位时都是隐性的加分项——面试官不会专门问你"内存分几段"，但会在你答不上来的时候，判断出你没有系统学过。反之，一个 C 语言和内存布局扎实的人，学任何一款新 MCU 都只是几天的事。

| 篇目 | 内容 | 难度 |
|---|---|---|
| [1.1 C 语言（嵌入式视角）](01-C语言（嵌入式视角）.md) | 指针与多级指针、结构体/联合体/位域、位操作、函数指针与回调、`volatile`/`const`/`static` 的真实含义、内存对齐与大小端 | ★★ |
| [1.2 编译链接与内存布局](02-编译链接与内存布局.md) | 预处理→编译→汇编→链接、启动文件与中断向量表、链接脚本、map 文件、.text/.data/.bss/heap/stack | ★★★ |
| [1.3 数据结构与算法](03-数据结构与算法.md) | 环形缓冲区、链表/队列/栈在嵌入式中的实际用途、查表法替代计算、刷题建议 | ★★ |
| [1.4 计算机组成与操作系统原理](04-计算机组成与操作系统原理.md) | CPU 取指译码执行、Cache、总线与 DMA、中断机制、进程线程/调度/同步/死锁 | ★★★ |
| [1.5 上位机与工具开发](05-上位机与工具开发.md) | Qt、串口屏、LVGL、Web 上位机、Python 快速工具，各自适用场景 | ★★ |

## 适合谁

- **零基础**：先看 1.1，其余可以边做项目边补。
- **转行程序员**：重点看 **1.2**，这是最容易缺的一环。
- **在职补短板**：1.3 和 1.4 大概率是你以为自己会、其实没系统学过的地方。

## 通读顺序建议

```
1.1 C 语言  →  1.2 编译链接与内存布局  →  1.4 计算机组成与操作系统原理
                                              ↓
                                    1.3 数据结构与算法（可穿插）
                                              ↓
                                    1.5 上位机（按需，非主线）
```

**1.2 是全章最重要的一篇。** 如果你的时间只够读一篇，读它。
