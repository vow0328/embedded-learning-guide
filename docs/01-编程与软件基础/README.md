# 1. 编程与软件基础

**这是全教程的地基。它看起来最不"嵌入式"，但决定了你能走多远。**

第 1 章的内容在应聘任何嵌入式岗位时都是隐性的加分项——面试官不会专门问你"内存分几段"，但会在你答不上来的时候，判断出你没有系统学过。反之，一个 C 语言和内存布局扎实的人，学任何一款新 MCU 都只是几天的事。

| 篇目 | 内容 | 难度 |
|---|---|---|
| [1.1 C 语言（嵌入式视角）](01-C语言（嵌入式视角）.md) | 指针与多级指针、结构体/联合体/位域、位操作、函数指针与回调、`volatile`/`const`/`static` 的真实含义、变量住在哪个段（`.text`/`.data`/`.bss`/栈/堆）、内存对齐与大小端 | ★★ |
| [1.2 数据结构与算法](02-数据结构与算法.md) | 环形缓冲区、链表/队列/栈在嵌入式中的实际用途、查表法替代计算、刷题建议 | ★★ |
| [1.3 计算机组成与操作系统原理](03-计算机组成与操作系统原理.md) | 总线与 DMA、中断机制、崩溃现场定位、进程线程/调度/同步/死锁 | ★★★ |
| [1.4 上位机与工具开发](04-上位机与工具开发.md) | Qt、串口屏、LVGL、Web 上位机、Python 快速工具，各自适用场景 | ★★ |

## 适合谁

- **零基础**：先看 1.1，其余可以边做项目边补。
- **转行程序员**：重点看 **1.1**，这是最容易缺的一环。
- **在职补短板**：1.2 和 1.3 大概率是你以为自己会、其实没系统学过的地方。

## 通读顺序建议

```
1.1 C 语言  →  1.3 计算机组成与操作系统原理
                     ↓
            1.2 数据结构与算法（可穿插）
                     ↓
            1.4 上位机（按需，非主线）
```

**1.1 是全章最重要的一篇。** 如果你的时间只够读一篇，读它。
