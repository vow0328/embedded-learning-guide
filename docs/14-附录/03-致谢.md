## 开源教程来源

本教程的初版整理，参考并感谢中科大 RoboWalker 战队的开源培训内容（B 站 UP 主 TrojanGeneric 的《中科大 RM 电控合集》）。

合集入口是这一集《电控入门导论》，27 分钟，先看它能快速知道整套内容的结构：

https://www.bilibili.com/video/BV1z14y1G77V

配套代码和其他资料在上游仓库里。**建议用 GitHub 这一份**——作者另外提供过一个中科大校内 GitLab 的地址，校外访问不稳定，不适合当主要入口：

https://github.com/yssickjgd/robowalker_train

**这也是这份教程推荐给初学者的一条入门路径**——它的优点是上手快、节奏友好，适合从零开始建立对外设和调试的直观认识。需要提醒的是：**教程可以看，代码不要照搬。** 照着敲一遍之后，关掉视频自己从头实现一遍，才算真正学到手。
