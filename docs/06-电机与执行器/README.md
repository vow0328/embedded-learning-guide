# 6. 电机与执行器

**这是嵌入式领域软硬结合最紧密、薪资天花板较高的方向之一。**

电机控制的全称其实是"电机控制系统"——它是**电机本体 + 驱动电路 + 检测环节 + 控制算法 + 实时代码**这五件事的耦合。任何一环不懂，都会卡住，而且症状往往出现在别的环节上：

- 电流环震荡，根因可能是采样电阻的布局；
- 电机一转就复位，根因可能是母线电容不够或电源限流；
- 低速转矩脉动，根因可能是死区没补偿或编码器分辨率不够。

所以这一章**刻意把硬件和软件放在一起讲**。只学 FOC 公式而不懂驱动电路，是做不出能转的系统的。

## 适合谁

- **电机控制方向**：全章必读，这是你的主线。
- **机器人/无人机方向**：6.1、6.3、6.5 必读。
- **软件方向但对运动控制感兴趣**：从 6.1 读起，6.2 至少要能看懂——不懂驱动电路，你永远只能调别人做好的板子。
- **硬件方向**：6.2 是你的主线，其余了解即可。

## 通读顺序建议

```
6.1 电机基础与选型
      ↓
6.2 电机驱动电路  ← 硬件侧核心
      ↓
6.4 位置与电流检测  ← 控制效果的物理上限由它决定
      ↓
6.3 电机控制算法  ← 软件侧核心
      ↓
6.5 模块化的执行器
```

**一个重要的顺序建议：先让电机"能转"，再让它"转得好"。**

先用最简单的六步换相或开环驱动把电机转起来，再用示波器看清电流波形，最后才上 FOC。直接冲 FOC 的人，往往在"电机不转"这一步就卡死了，而且不知道问题出在代码、驱动还是接线。

**安全提醒**：电机和功率电路是这份教程里最容易损坏器件、也最容易伤人的部分。上电前务必做限流保护，调试时注意旋转部件的机械防护。
