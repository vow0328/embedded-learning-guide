# 6.5 模块化的执行器

> **前置知识**：[6.1 电机基础与选型](01-电机基础与选型.md) · [2.3 通用外设](../02-MCU与体系结构/03-通用外设.md)
>
> **掌握标准**：能正确驱动舵机和步进电机，并说清它们各自的控制精度、速度限制和失效模式
>
> **对应岗位**：机器人工程师 · 无人机工程师 · 嵌入式软件工程师 · 3D 打印机/自动化设备工程师
>
> **练手建议**：用定时器输出 PWM 控制一个舵机做平滑扫动，再用另一个定时器配合驱动器让步进电机走固定的步数，用肉眼或标记确认它有没有丢步

## 为什么把这两个放在一篇

舵机和步进电机的共同点很实际：**它们都把复杂的控制问题封装在了模块内部，让使用者只需要会数脉冲或者会给脉宽。**

舵机内部自带位置闭环，你给脉宽它就给角度。步进电机配上驱动器，你给脉冲它就一步步走。这带来一个共同的好处——**入门门槛极低，几十分钟就能让东西动起来**；也带来一个共同的坏处——**你很容易以为它们很精确、很可靠，直到项目真正跑起来才发现不是。**

这一篇的重点不在"怎么让它动"，而在**它们的失效模式**：舵机什么时候会抖、会烧；步进电机什么时候会丢步、会振。这些才是让你在项目里踩坑的地方。

**顺带说清一件事**：按上面这个标准——"控制被封装进模块、你只给一个简单信号"——**无刷电机配成品电调其实也属于这一类**，同样是给个油门就转。它没有收进这一篇，是因为它先是一个**选型决策**（自己搭驱动还是买模块），所以写在了 [6.1 电机基础与选型](01-电机基础与选型.md) 的"无刷怎么落地：自研驱动，还是买成品电调"一节里。**如果你正是来这里找无刷的，去那一节。**

## 舵机：一个封装好的位置闭环

拆开一个标准舵机，里面是四样东西：

1. 一台**小型直流有刷电机**（少数高性能型号用无刷）；
2. 一组**减速齿轮**，把电机的高转速小扭矩变成输出轴的低转速大扭矩；
3. 一个**电位器**，和输出轴同轴相连，用来测量输出轴当前的角度；
4. 一块**控制板**，把电位器测到的角度和你给的目标角度比较，用 PID 或者更简单的比例控制去驱动电机，直到两者一致。

所以舵机本质上是一个**位置伺服系统**。你在外面看到的只有三根线：电源（通常红色）、地（棕色或黑色）、信号（橙色或白色）。

| 参数 | 含义 | 选型时的意义 |
|---|---|---|
| 角度范围 | 常见 180 度，也有 270 度 | 决定机构的运动幅面 |
| 工作电压 | 常见 4.8V 和 6.0V 两档（典型值，以数据手册为准） | 电压越高扭矩和速度越大，超额定会烧 |
| 堵转扭矩 | 输出轴被卡住时的最大扭矩 | 核心指标，通常要留 2 倍以上余量 |
| 堵转电流 | 输出轴被卡住时的电流 | 决定电源和线径，可达空载的十倍 |
| 速度 | 转 60 度所需时间 | 注意这个值是在空载下测的 |

**金属齿与塑料齿**的选择很实际：塑料齿便宜、安静，但扭矩稍大或受冲击就容易**扫齿**（齿被打掉）。金属齿耐用得多，代价是噪声大、磨损后会掉金属屑。做会被撞到的机器人关节，多花钱买金属齿是值得的。

## PWM 控制：决定角度的是脉宽，不是占空比

这是舵机最容易被误解的一点。

普通的 PWM 调速是用**占空比**控制输出大小。舵机完全不是这个逻辑——它看的是**高电平持续的时间（脉宽）**，周期是固定的。

行业约定是：**周期 20ms（也就是 50Hz），脉宽 0.5ms 对应一个极限角度，1.5ms 对应中位，2.5ms 对应另一个极限。**（典型值，以数据手册为准）

为什么是这个约定？因为这是最早期的模拟舵机电路自然形成的：20ms 是当时能可靠传输多路信号、又不至于让电机控制信号断续的折中；0.5 到 2.5ms 是电路能分辨的范围。这个约定沿用了几十年，成了事实标准。

**但这里有一个新手的必经之坑：实际范围因型号而异。**便宜的舵机可能只认 0.7~2.3ms，有些只能到 1.0~2.0ms，也有宽范围的能到 0.3~2.7ms。如果你按理论值给 0.5ms，舵机会**顶到机械限位还在使劲转**，表现为持续嗡嗡响、电流大增、齿轮发热——**这是最常见的烧舵机方式。**

正确的做法是**标定**：上电后慢慢把脉宽从 1.5ms 往两边推，每次增加一点点，观察输出轴什么时候顶到限位或者开始持续响，把那个值记下来作为软件的软限位，再往内缩一点。**永远不要相信理论值，永远不要不标定就用满量程。**

## 角度范围与那三种"舵机"

标着 180 度的舵机，输出轴能转约 180 度，中间任何位置都可以停住（受电位器反馈控制）。

**270 度的舵机**只是把机械和反馈范围做大了，控制方式完全一样，但同样的脉宽对应的角度不同，标定必须重做。

**360 度连续旋转舵机则是另一个东西。**它的名字容易让人误解成"能转一整圈的位置舵机"，实际上**它内部已经去掉了位置反馈**——你给的脉宽不再代表角度，而是代表**转速和一个方向**。1.5ms 是停止，往两边偏就是正反转调速。它本质上变成了一台**调速直流电机**，**完全没有位置控制能力**。

**这是买错就白买的一类器件。**想做"转到某个角度"的控制，买成连续旋转舵机，会发现它只会一直转，永远停不到你想要的位置。

## 数字舵机与模拟舵机

老式的**模拟舵机**内部用模拟电路比较脉宽和电位器电压，控制频率就是 PWM 的 50Hz，响应偏慢、保持力偏弱、容易抖。

**数字舵机**内部有单片机，把输入脉宽解码成目标位置，然后用远高于 50Hz 的频率（常见几百赫兹到上千赫兹）去驱动电机。带来的效果是：**响应更快、保持力更强、死区更小、回中更准**，代价是**耗电更大、对电源要求更高、价格更贵**，而且静止时因为一直在高频调整，会有持续的轻微电流和噪声。

一个实用判断：如果需要"按住一个角度不动"（比如机械臂托着东西），数字舵机好得多；如果只是偶尔摆一下（比如航模的副翼），模拟舵机够用且便宜。

## 堵转电流与供电陷阱

**堵转时电流最大**，这是舵机最需要记住的一条。舵机被外力顶住、或者被指令要求转到一个它到不了的角度时，电机会一直以最大力矩顶着，电流达到堵转值。

- **不能长时间堵转**：堵转电流可能是空载的十倍（典型量级，以数据手册为准），电机的铜损正比于电流的平方，热量会在很短时间内积累起来，先烧电机绕组，再烧控制板。
- **多舵机系统必须算总电流**：一个机器人上装了 8 个舵机，如果同时动作，哪怕只有两个堵转，总电流也可能超过你电源的额定输出。**电源功率要按"所有舵机同时堵转"这个最坏情况留余量**，或者至少要在软件上做**分时动作**，避免所有舵机同时启动。

**最常见的翻车原因，是舵机和单片机共用一路电源。**舵机启动或堵转的瞬间会拉出一个大电流尖峰，电源线的电压被拉下去，单片机的供电随之跌落，触发欠压复位。现象很典型：**舵机一动，程序就重启**，或者舵机动一下、屏幕黑一下、蓝牙断一下。很多人会去怀疑自己的代码，其实问题全在供电上。

解决办法按优先级排：

1. **舵机单独供电**——用独立的电池或者独立的稳压模块，只把地线和单片机连在一起（共地是必须的）。
2. **在舵机电源入口并联大容量电解电容**，让它就近提供瞬态电流，减小对电源线的冲击。
3. **电源线要粗**，舵机那几根细的杜邦线在几个安培的电流下压降很可观。
4. **不要在舵机运动和传感器采样之间共享走线或连接器**。

## 舵机的速度特性

**舵机是按自己的速度转过去的，不是你想给什么速度就是什么速度。**

你给的是目标角度，舵机内部用最大能力（或内部限定的速度）去逼近这个角度。所以：

- 想让舵机**缓慢平滑地转**，唯一的方法是在你的代码里**把目标角度切成很多小步**，每几十毫秒更新一次，让舵机去追一系列小目标。这在机器人里叫"插值"或者"轨迹生成"。
- 不同型号的舵机速度差别很大，大扭矩舵机通常转得更慢。选型时要看"转 60 度所需时间"这一项，并且**注意这个值是在空载下测的**，带负载会明显变慢。

如果做的是需要规划轨迹的项目，这套插值的思路和 [5.4 运动规划与运动学](../05-控制与算法/04-运动规划与运动学.md) 里讲的是一个东西。

## 总线舵机：机器人项目的主流选择

传统舵机的信号线是单向的（你只能发指令，读不到任何状态），而且每个舵机都要占用一个 PWM 引脚。装到 10 个以上舵机的机器人上，问题就很明显了。

**总线舵机**（也叫串行总线舵机）把这一层彻底改了：多个舵机挂在同一条串口总线上，每个有自己的 ID，你可以发指令、也可以**读回它当前的角度、速度、负载、温度、电压**。有的还能在线调整 PID 参数、设置最大扭矩、设置软限位。

好处是显而易见的：**引脚从 N 个变成一个，能读回反馈所以可以判断是否堵转，能调参数所以不用凑合着用。**代价是价格更高、需要写一套协议解析代码、并且总线的带宽是共享的。

**做机械臂、四足、人形这类多关节机器人，总线舵机基本是默认选择。**如果你只是想做一个两三个舵机的小车或者云台，普通舵机更省钱省事。舵机的协议解析属于典型的通信帧处理问题，方法论见 [5.5 数据处理与校验](../05-控制与算法/05-数据处理与校验.md)。

## 舵机常见故障

| 现象 | 常见原因 |
|---|---|
| 抖动、来回小幅摆动 | 供电不稳（电压在掉）、信号线受干扰、负载和舵机扭矩不匹配 |
| 嗡嗡响但不转 | 顶到机械限位或负载太重，处于堵转状态，**继续这样很快会烧** |
| 角度不准、两边不对称 | 脉宽范围没有标定，或者用了超出机械范围的值 |
| 响声正常但没劲 | 供电电压不足，或者电源内阻太大带不动 |
| 发热严重 | 长期堵转、或者内部齿轮阻力变大（塑料齿磨损） |

## 步进电机：脉冲计数式的定位

步进电机的工作方式和前面所有电机都不一样。它**不给连续电流让电机持续旋转**，而是用两相（或多相）绕组产生一系列离散的磁场状态，每一步都把转子"掰"到下一个固定的位置。

对外的接口简单到极致：**一个脉冲引脚（每来一个脉冲走一步）、一个方向引脚（决定往哪边转）**。你发 200 个脉冲，它就转一圈（对 1.8 度步距角的电机而言，典型值，以数据手册为准）。

它的核心卖点是**开环定位**：控制器只需要数自己发了多少脉冲，就"认为"电机走了多少步。**不需要编码器，不需要 PID，不需要反馈回路**——这在成本和开发时间上都是巨大的优势。3D 打印机、雕刻机之所以能做出来，很大程度靠的就是这一点。

## 步距角与细分：一个必须澄清的误解

**步距角**是整步模式下每来一个脉冲转子转过的角度，常见值是 1.8 度（两相电机，一圈 200 步），也有 0.9 度、7.5 度等其他规格（典型值，以数据手册为准）。

**细分驱动**是驱动器提供的功能。它不再让绕组电流在两个离散状态之间跳变，而是让两相绕组的电流按**正弦和余弦的规律连续变化**，这样磁场的方向就能连续旋转，转子也就停在了原本整步之间的中间位置上。常见细分有 1/2、1/4、1/8、1/16、1/32、1/64，甚至 1/256。

细分带来两个明确的好处：

1. **分辨率提高**——每个脉冲转过的角度变成整步的几分之一。
2. **运行更平滑**——电流连续变化，转矩脉动小，低速时不容易共振和啸叫。**这是细分在实际项目中更重要的价值。**

**但细分不能提高定位精度。**这是最容易误解的一点，值得单独强调。

- **分辨率**指的是"能分辨的最小步长"，细分能提高它。
- **精度**指的是"走到目标位置时，实际位置和目标位置的差"，**它取决于电机的机械加工误差、装配误差、齿槽效应、以及负载的反作用**，细分一点都改变不了。

一台步距角 1.8 度的廉价电机，用 1/64 细分之后每个脉冲对应 0.028 度（名义值），但它的实际落点误差可能是正负零点几度——**机械误差早就在那里了**。细分只是把电流正弦化了，并没有让电机变精密。

理解了这一点，你就不会为了"提高精度"去无脑加大细分，而是会知道：**要高精度要么换更好的电机和减速箱，要么加编码器做闭环，要么就别用步进。**

## 驱动器：你需要管的事其实很少

步进电机驱动器（常见的像 A4988、TMC2208、DM542 这一类，仅作类型举例）把三件事全包了：

- **恒流斩波**：绕组电流按设定值维持恒定，而不是简单加电压。这是步进电机能高效输出扭矩的关键——**它本质上是一个电流控制回路**，通过快速通断来维持电流。你会听到电机在静止时发出轻微的"嘶嘶"声，那就是斩波在工作的声音，正常现象。
- **细分**：由拨码或者寄存器配置。
- **电流设定**：通常用一个电位器或者寄存器设定峰值电流，**必须按电机额定电流设置**。

所以对单片机来说，**你只需要输出脉冲和方向两个信号**，加上一个可选的使能信号。电流控制、细分切换、保护，全部不在你的代码里。

**这里的坑**：电流设定过大是烧步进电机的第一原因。很多人"怕它没力"就把电流调满，结果电机长期超额定电流运行，绕组过热，最终退磁或者烧断。**按电机铭牌的额定电流设置，宁小勿大。**

## 加减速曲线是必需的

**步进电机不能直接高速启动。**

原因很直观：电机的转子有惯量，启动的瞬间它还是静止的。而你如果一开始就给很高的脉冲频率，转子来不及跟上磁场的变化，就会**直接失步**——不是走得慢一点，而是彻底跟不上，原地抖或者停住。

所以**必须有一段加速过程**：从低频起步（比如每秒几百个脉冲），然后按一定的规律把频率提上去，到达目标速度后匀速运行，结束前再对称地减速下来。这个频率和时间的对应关系就是**加减速曲线**。

- **梯形曲线**：加速段用恒定加速度。简单、好实现、占用计算资源少，是最常用的。
- **S 曲线**：加速度本身也是渐变的，起停更柔和、冲击更小、也不容易激励机构共振，代价是实现复杂一些。做精密设备或者有柔性负载的场合值得用。

这一部分的算法细节在 [5.4 运动规划与运动学](../05-控制与算法/04-运动规划与运动学.md) 里有完整的讲解。

**起步频率能设多低取决于负载**——负载惯量越大、需要的启动频率就越低。调试时如果发现电机一加速就丢步，**第一件事是把加速度降下来**，而不是去加大电流。

## 失步：开环的根本问题

**失步指的是转子没能跟上脉冲的节奏，实际走的步数少于控制器发出的脉冲数。**

什么时候会失步：

- **加速度太大**——最常见的原因，尤其是启动和换向的瞬间；
- **转速超过了矩频特性允许的范围**——转得越快能提供的扭矩越小，超过某个点就带不动负载了；
- **负载突变**——机构卡了一下、被撞了一下、切削力突然增大；
- **电流设定太小**，扭矩储备不足。

**最要命的一点是：开环系统根本不知道失步发生了。**控制器发完 1000 个脉冲就认为走了 1000 步，而实际可能只走了 987 步，而且误差会一直累积下去。3D 打印机打了一半错位、雕刻机雕废一整块料，往往就是这个原因。

缓解手段，按优先级排：

1. **降低加速度，留速度余量**。把工作速度设在矩频特性允许值的百分之六七十（经验值，视机构而定），比什么都管用。
2. **把负载惯量和电机扭矩匹配好**，不要用一台小电机去硬带一个重机构。
3. **保证电流设定正确**，不要因为怕发热就调得过小。
4. **加编码器做闭环**。这是根本解法，但要注意：**加了编码器之后，系统本质上是"闭环步进"**——编码器能检测到失步并报警，有些驱动器还能自动补步。不过它并**不会**把步进电机变成伺服电机：闭环步进依然有矩频特性，只是在丢步时能发现、能补偿。真想从根本上解决，还是换伺服。

## 矩频特性与发热

**矩频特性**说的是：**转速越高，能提供的转矩越低。**这不是设计缺陷，而是步进电机的固有物理特性——绕组是电感，转速越高，电流来不及建立到设定值，实际电流就越小，扭矩自然就小。这也是为什么步进电机在高速时"没力气"。

所以步进电机的典型工作区间是**中低速**。真要做高速高动态的场合，它就不是合适的选择。

**发热**是另一个要接受的现实：**步进电机长期满电流运行会烫，这是正常的**。因为它不管走不走都在通电（恒流斩波一直在维持电流），铜损一直在产生。外壳温度到六十度甚至更高都不算异常（具体限值以数据手册为准），但那是在通风良好的条件下。

实际使用中要注意：

- **封闭空间里要降额**，把电流设定调低一些；
- **别让手长时间摸上去**，也不要让线缆贴在电机外壳上；
- **精度要求高的场合，热膨胀也会影响机构尺寸**，这也是工业设备上要用闭环伺服的原因之一。

## 静态保持：耗电但不白花

步进电机**停止时仍然通电**，用电流把转子牢牢锁在当前位置。这叫静态保持，是它相对有刷电机的一个优势——**不需要机械抱闸就能对抗外力**。

代价是**停止时也在耗电和发热**。所以：

- 有些电池供电的设备，会把**使能信号关掉**让电机自由，省电，代价是位置会被外力带走；
- 有些场合下电机自带的微弱保持力就够（比如水平导轨），可以关使能；
- **需要保持力的竖直轴（Z 轴、机械臂）绝对不能关使能**，否则负载会在重力作用下自己掉下来，还可能砸坏东西。这种场合应当考虑加机械抱闸或者用自锁型的传动（比如丝杠、蜗轮蜗杆）。

## 步进电机常见故障

| 现象 | 常见原因 |
|---|---|
| 完全不动 | 使能信号没给、驱动器没供电、脉冲信号电平不匹配 |
| 抖动、原地响但不转 | 相位接错（某一相的两根线接反或串到了另一相）、细分设置和接线方式对不上 |
| 丢步、加工错位 | 加速度太大、速度超过矩频特性允许值、电流设定太小、机构卡涩 |
| 方向反了 | 方向引脚的电平逻辑反了——先改软件再改接线，别急着动线 |
| 异响、啸叫 | 斩波频率和机构共振、细分太低、电压过低 |
| 烫得厉害 | 电流设定过大、频率太低导致长时间大电流、通风不良 |

## 学习建议

1. **先买一个舵机和一个带驱动器的步进电机。**它们几乎是所有运动控制入门项目里最便宜的两件事，加一起不到一百块钱（价格随市场波动，这里只是量级参考），却能让你把这一篇的所有概念都验证一遍。
2. **一定要做标定这件事。**舵机的脉宽范围、步进电机的电流和细分、加减速曲线的加速度，这些参数都必须在你自己的硬件上试出来，不能照抄别人的。
3. **给舵机单独供电，是新手第一个必须养成的习惯。**不这么做，你会花大量时间去查一个根本不在代码里的 bug。
4. **步进电机调参的顺序是：先低速转起来，再调电流和细分，最后才调加减速。**顺序反了会一直在失步和发热之间来回折腾。
5. **想清楚你的项目到底需不需要位置反馈。**如果只是"走到大概位置再靠机械限位对齐"（很多打印机的原点就是这样），开环步进非常划算；如果要"每次都精确停到指定角度并且不能出错"，就该考虑闭环步进或者直接上伺服，不要试图用软件去弥补开环的先天缺陷。

## 小节总结

舵机和步进电机的价值在于**把复杂的控制封装进了模块**，让入门门槛降到极低。但它们各自有一个必须理解的失效边界。

**舵机的边界是供电和标定。**决定角度的是脉宽而不是占空比，而这个脉宽范围必须在你自己的舵机上实测标定，按理论值给满量程就是烧舵机的标准流程。同时，舵机和单片机共用电源是新手最经典的翻车方式——**舵机一动程序就重启，根因永远在电源上，不在代码里。**多舵机系统要按最坏情况算总电流，做分时动作。

**步进电机的边界是失步。**细分能提高分辨率和运行平滑度，但**不能提高定位精度**，精度取决于机械和负载。开环系统在失步发生时毫无察觉，误差还会累积；缓解靠的是留速度余量、合理的加减速曲线和正确的电流设定，根本解法是加编码器或者换伺服。矩频特性和发热是它的固有代价，接受它、按中低速工况去设计，比对抗它更明智。

最后一条判断：**这两个器件都便宜、都好用、都有明确的能力边界。真正的工程能力不在于把它们驱动起来，而在于知道什么时候该用它们、什么时候该换掉它们。**
