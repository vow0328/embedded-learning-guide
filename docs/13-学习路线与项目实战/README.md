前面 12 章讲的是"有哪些知识"，这一章讲的是"怎么把这些知识变成你的能力，以及怎么把它展示给别人看"。

## 适合谁

所有人，但**使用时机不同**：

- **刚开始学**：先读 13.1 和 13.2，确定第一个项目和装备。
- **学了一阵子**：读 13.3 找资源，读 13.2 挑下一个难度的项目。
- **准备找工作**：直接读 13.4，然后用它的框架回头审视自己的项目。

## 通读顺序建议

```
13.1 方向路线图  →  13.2 项目实战阶梯（选定第一个项目）
                            ↓
                    动手做（回到前面各章查知识）
                            ↓
                    13.3 资源地图（卡住时找资料）
                            ↓
                    13.4 求职准备（做完了、要展示了）
```

## 这一章的核心观点

**项目经历是嵌入式求职的决定性因素，比技能清单重要得多。**

原因在于：技能清单是可以背的，项目经历不能。面试官问"你这个项目里最难的地方是什么、你怎么解决的"，背不出来。而这个问题几乎是必问的。

所以：

- **不要等到"学完了"才做项目。** 你永远不会觉得学完了。
- **项目不必高大上。** 一个把细节讲透的循迹小车，比一个照抄教程的四轴飞行器更有说服力。
- **做完要复盘。** 做完不复盘，等于只拿到了一半的收获——另一半在"我当时为什么这么选、如果重来会怎么改"里。

具体方法见 [13.2](02-项目实战阶梯.md) 和 [13.4](04-求职准备.md)。
