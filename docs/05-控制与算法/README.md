# 5. 控制与算法

**算法是嵌入式从"能跑起来"走向"跑得更好"的关键一环。**

算法不等于 PID。它涵盖控制、滤波、运动学、数据处理等多个方面。很多时候，系统效果不好并不是硬件不行，而是算法和模型没有选对。反过来，合适的算法往往能用很小的代码量，解决靠硬件或蛮力调参难以解决的问题。

## 适合谁

- **控制/电机/机器人方向**：全章必读，5.2~5.4 是核心。
- **物联网/通信方向**：重点读 5.5（帧解析、CRC 是通信的基本功）。
- **纯应用开发**：5.2 和 5.5 读完即可，其余按需。

## 通读顺序建议

```
5.1 总览（先知道有哪些工具）
      ↓
5.2 控制算法  ← 先会用 PID，别急着学卡尔曼
      ↓
5.5 数据处理与校验  ← 任何涉及通信的项目都要用
      ↓
5.3 滤波与姿态解算  →  5.4 运动规划与运动学
      ↓
5.6 进阶索引（遇到具体问题时再按图索骥）
```

**一个诚实的提醒**：算法这条路没有终点，也不要追求面面俱到。更现实的做法是"用到什么学什么"——项目需要哪类算法，就重点补哪一类。**先把 PID 和滤波用熟，比草草看过十种高级算法有用得多。**
