# 2. MCU 与体系结构

**这一章是从"会写 C 代码"到"能让一块板子按你的意思动起来"的跨越。**

这是整个教程里"投入产出比"最高的一章。学完之后你就具备了做项目的最小能力——从这一章开始，你就可以动手做真实的东西了。

| 篇目 | 内容 | 难度 |
|---|---|---|
| [2.1 单片机平台选型](01-单片机平台选型.md) | STM32 / Arduino / ESP32 / MSP430 对比；国产 MCU（GD32、CH32、极海、国民技术等）；怎么选第一块板 | ★ |
| [2.2 Cortex-M 架构与启动流程](02-Cortex-M架构与启动流程.md) | 寄存器模型、特权级与模式、中断向量表、复位序列、MSP/PSP、启动文件做了什么 | ★★★ |
| [2.3 通用外设](03-通用外设.md) | GPIO/UART/SPI/I2C/TIM/PWM/ADC/DMA 的配置要点与常见坑 | ★★★ |
| [2.4 中断系统与低功耗](04-中断系统与低功耗.md) | NVIC 优先级分组、抢占与嵌套、EXTI、中断服务函数禁忌；睡眠/停止/待机模式与唤醒源 | ★★★ |
| [2.5 Flash 存储与参数管理](05-Flash存储与参数管理.md) | Flash 擦写特性与寿命、EEPROM 模拟、磨损均衡、掉电保护、双备份参数区、FatFs 与 LittleFS | ★★★ |

## 适合谁

- **所有人**：这一章是必经之路，没有例外。
- **硬件方向**：2.3 和 2.4 也要读——你需要知道软件在期望硬件做什么，才能联合定位问题。

## 通读顺序建议

```
2.1 平台选型（选板子）
      ↓
2.3 通用外设  ←→  边读边在板子上跑
      ↓
2.4 中断系统与低功耗         ← 读之前先看 2.2 的《异常与中断模型》《NVIC》两节
      ↓
2.2 Cortex-M 架构与启动流程   ← 整篇放到后面读，理解会更深
      ↓
2.5 Flash 存储与参数管理      ← 做完整项目时回来读
```

**2.2 整篇建议放到后面读。** 它讲的是底层机制，如果你还没跑过几个外设，读起来会很抽象。先会用，再懂原理，效率高得多。

唯一的例外是其中的《异常与中断模型》和《NVIC：真正干活的中断控制器》两节：**2.4 整篇建立在这两节上**（中断怎么进、优先级怎么算、嵌套怎么发生，都是那一篇的结论），所以要在读 2.4 之前先看完它们。这两节不长，半小时够了，读完再回头看 2.2 的其余部分也不冲突。
