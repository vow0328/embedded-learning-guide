# 1.2 焊接

焊接是电控的基本功。再好的电路设计，焊不好就是废铁；再精密的芯片，一个虚焊就能让你调试到怀疑人生。

## 焊接工具

- **电烙铁**：推荐恒温烙铁（如白光T12、SH72），温度设在320-360°C。不要用那种20块钱的烙铁，温度不稳，焊出来全是虚焊（新手推荐稳定的电烙铁，若条件受限，可以用20块的电烙铁练习洞洞板焊接后再进行项目焊接）。
- **焊锡丝**：推荐0.8mm有铅焊锡（含松香芯），有铅的比无铅的好焊很多，新手别跟自己过不去。
- **助焊剂/松香**：涂在焊盘上可以帮助焊锡流动，减少虚焊。
- **热风枪**：焊贴片元件用的，特别是QFP、QFN封装的芯片，没有热风枪基本焊不了。
- **加热台**：功能和热风枪类似，不用担心器件焊接时错位。
- **吸锡带/吸锡器**：焊错了用来返工的，必备。
- **镊子**：夹取贴片元器件用的，建议买尖头防静电镊子。

## 焊接方法

### 直插元件（最简单）

元器件引脚穿过PCB孔 → 翻到背面 → 烙铁尖同时接触引脚和焊盘 → 送锡 → 等焊锡润湿焊盘形成锥形 → 撤烙铁。

关键点：烙铁先加热焊盘和引脚2秒再送锡，不要直接把焊锡怼到烙铁上化（焊锡对着元器件引脚，焊枪在引脚另一端，慢慢向焊枪靠近）。

### 贴片电阻电容（0805/0603封装）

先在一个焊盘上预上锡 → 用镊子夹住元件放到位 → 烙铁融化预上的锡固定一端 → 再焊另一端。

0402及以下封装建议用热风枪+锡膏，手焊容易疯（配备好镊子，若无锡膏最好使用好一点的锡，并注意温度不要过高，加热时间不要太长）。

### 芯片（QFP/LQFP封装，比如STM32F103C8T6）

先对准一个角的引脚焊固定 → 对角再固定一个 → 确认位置正确 → 逐个引脚焊接或者直接拖焊。

拖焊技巧：烙铁蘸助焊剂，沿引脚方向轻轻拖过去，多余的锡会被带走。桥连了就用吸锡带吸掉。

### QFN/BGA封装（进阶）

需要用锡膏+热风枪或者回流焊，手焊几乎不可能。新手暂时不用学这个。（建议使用钢网，锡膏，好镊子及加热台进行尝试）

## 焊接完成后的检查

- **目视检查**：用放大镜或手机微距看每个焊点，确认没有桥连（两个引脚被锡连在一起）、虚焊（看着焊上了实际没连）、漏焊。
- **万用表检查**：用蜂鸣档测量相邻引脚有没有短路，重点检查电源和地有没有短路（上电前必查！）。
- **上电测试**：先不插芯片，只测电源部分的电压是否正常（3.3V、5V），正常之后再插芯片。避免一上电就烧芯片的悲剧。（最简单的办法是焊接一部分，测试一部分）
- **在线测量**：用万用表对照原理图，逐个测量关键节点的电压，比如芯片的VCC引脚、复位引脚、晶振两端的波形（需要示波器）等，验证各模块是否按预期工作。
- **限流保护**：第一次给一块新焊好的板子上电时，建议使用带限流功能的可调电源（将限流设在预期电流的1.5倍左右），一旦出现短路，电源会自动限流保护，不至于直接烧毁元器件。条件不具备时，可以串联一个小功率灯泡（5W左右）来限流，短路时灯泡会亮，正常时灯泡几乎不亮。

## 常见焊接问题与解决方案

- **虚焊**：表现为焊点看似完整，但实际上焊锡与焊盘或引脚之间没有形成良好的金属连接。原因通常是温度不够、加热时间太短或焊盘氧化。解决方法：重新加热焊点，必要时加少量新焊锡和助焊剂，确保焊锡完全润湿。
- **桥连**：表现为相邻两个焊点被多余的焊锡连接在一起，形成短路。解决方法：用吸锡带吸走多余的锡，配合助焊剂效果更好。
- **锡球**：焊接时飞溅出来的小锡珠落在板面上，可能造成短路。解决方法：用镊子或毛刷清除，焊接时助焊剂不要涂太多可以减少飞溅。
- **冷焊**：焊锡在高温下凝固，表面呈现粗糙、颗粒状，无光泽。原因通常是焊接过程中板子或元件发生了抖动。解决方法：重新加热使焊锡完全熔化，等待自然冷却，焊接过程中保持稳定不抖动。
- **焊盘脱落**：过度加热或多次返工导致PCB焊盘从基板上剥离，是不可逆的损伤。预防方法：控制加热温度和时间，每次加热不超过3-5秒，间隔冷却后再加热。一旦焊盘脱落，可以用飞线（细漆包线）直接连接到芯片引脚或走线来补救。

## 学习建议

焊接是一项强调动手的技能，理论看得再多，不如实际操作几块板子来得有效。建议新手按照这样的顺序练习：先在洞洞板上练习直插焊接，熟悉烙铁的手感和送锡的节奏；再找一些废旧的贴片元件练习0805封装的贴片焊接；然后挑战更小封装和更密间距的芯片。每个阶段都要认真检查焊点质量，发现问题及时纠正，不要带着坏习惯继续练。

焊接技术的理论不算困难，难点在于实操，所以与其找推荐视频，不如找一块焊接练习板多焊两遍进步得快。

## 小节总结

焊接就是电控人的"缝纫活"，手艺好不好，直接决定了板子能不能跑稳。这块内容没什么高深理论，核心就是通过烙铁控温、助焊剂铺路，让焊锡乖乖听话，把元器件和焊盘稳稳地"粘"在一起。

从直插、贴片到密脚芯片，每种封装都有对应的"套路"：直插靠预热，贴片靠固定，芯片靠拖焊。一个合格的焊点得长得像个光滑的小火山，而不是圆滚滚的锡球或者发灰的冷焊点。最关键的是，焊完别急着通电，必须先过目检和万用表这两关，特别是电源和地有没有短路，这是救命的检查。

总而言之，焊接不需要你做模拟电路分析，它只需要你心细、手稳、舍得用助焊剂。板子焊得漂亮，不仅调试起来省心，看着也是一种享受。
