# 1.1 电路设计

电路设计是电控的硬件基础，从简单的LED驱动电路到复杂的电机驱动板、主控板，都需要掌握一定的电路设计能力。

## 第一阶段：看懂电路

学习电路设计的第一步，不是马上去搞懂每个电路的工作原理，而是先学会看原理图，理解每个模块的功能和作用。推荐从一块STM32最小系统板的原理图入手，把电源部分（LDO/DCDC降压电路）、晶振电路、复位电路、BOOT选择电路、SWD下载接口这几个基础模块逐一搞清楚，理解它们分别负责什么，而不是纠结内部的工作细节。

与此同时，要学会看数据手册（Datasheet）。数据手册是每一个元器件最权威的参考资料，重点关注三个部分：引脚定义（知道每个引脚是干什么的）、推荐应用电路（直接照着画，八九不离十）、电气参数（工作电压范围、最大电流、逻辑电平等）。一开始看不懂是正常的，坚持多看几次，慢慢就会习惯那种排版和表述方式。

读懂原理图之后，可以尝试对照实物板子去理解每一个元器件的位置和作用。推荐找一块现成的开发板（比如STM32最小系统板），边看原理图边对照实物，把电源指示灯、晶振、复位键、USB接口等逐一找到，理解它们在原理图中的对应位置。这种方式比单纯看图快得多，也更有成就感。

看原理图时要养成看网络标号的习惯。很多原理图并不是把所有连线都画出来的，而是用网络标号（Net Label）来表示连接关系，比如VCC、GND、USART1_TX等。看懂网络标号，才能真正理解信号的流向。

## 第二阶段：画原理图

能看懂原理图之后，下一步就是自己动手画。目前常用的EDA软件有以下几种：

- **立创EDA**：国产、免费、上手快，元器件库非常丰富，下单直接对接嘉立创，全流程无缝衔接，强烈推荐新手作为第一款EDA工具学习。
- **Altium Designer**：行业标准工具，功能强大，适合复杂项目和团队协作，但学习曲线较陡，建议有一定基础后再上手。
- **KiCad**：开源免费，在国外开源社区中使用广泛，功能也在持续完善，有兴趣可以了解。

建议从一个简单的项目开始练手，比如画一块STM32最小系统板，或者一个电机驱动模块（如TB6612驱动板）。画原理图有几个核心原则要牢记：

- **电源优先**。先把电源架构（输入电压、降压方案、各路电源的去向）搞清楚，再画信号部分。
- **去耦电容不能省**。每个芯片的VCC引脚旁边都要放一个100nF的去耦电容，这不是形式，是真的有用。高频噪声会通过电源引脚进入芯片，去耦电容的作用就是就近滤掉这些噪声，保证芯片供电稳定。
- **命名和注释要规范**。每个元器件都应有明确的位号（如R1、C3、U2）和参数标注（如100nF、10kΩ、STM32F103C8T6），方便后期焊接和调试时快速定位。
- 当电路规模变大时，可以考虑使用层次化原理图（Hierarchical Schematic），把不同功能模块分成独立的子图（电源模块、主控模块、通信模块等），顶层原理图只保留模块之间的接口关系。这样结构清晰，出问题时也方便定位。
- 立创EDA自带的库覆盖了绝大部分常用元器件，包括原理图符号和PCB封装。遇到冷门元器件找不到的情况，需要根据Datasheet手动创建符号和封装。学会自制封装是进阶必备技能，早点接触不吃亏。

## 第三阶段：画PCB

原理图画好之后，就可以导入到PCB编辑器里开始布局和布线了。新手最容易踩的坑，几乎都出在这一步：

- 布线的几个基本原则：电源线要粗、信号线要短、模拟和数字电路要分区布局、大电流路径要远离敏感信号线。
- 线宽太细：电源线建议不低于20mil，普通信号线不低于10mil（具体线宽需要根据实际电流计算，见后文导线宽度部分）。
- 没有铺铜接地：铺铜是PCB设计的标配操作，能有效降低地阻抗、改善EMC、提升散热。
- 过孔太少：铺铜如果没有足够的过孔连接上下地平面，等于没铺。
- 元器件摆放混乱：布局不合理会直接导致布线困难，信号路径绕来绕去，干扰加剧。
- 丝印层要认真对待：丝印层上应标注元器件位号、极性方向（电解电容正极、二极管阳极方向）、接口引脚定义等信息。这些标注在焊接时非常关键，能大幅减少焊错的概率，新手很容易忽视这一步。
- 板框与安装孔：板子的外形尺寸和固定孔的位置、直径，要提前和结构组确认好。安装孔周围要留有足够的铜皮间距，避免螺丝拧紧后造成短路。
- 关于多层板：新手一般从两层板开始。等积累了一定经验之后，可以了解四层板的叠层结构（通常是：信号层、地平面层、电源平面层、信号层）。四层板将地平面和电源平面独立出来，EMC性能和信号质量都显著优于两层板，是工程实践中更常见的方案。
- 布局和布线完成后，务必做DRC（设计规则检查），确认没有未连接的网络、没有间距违规、没有孤立铜皮。DRC报错不清零不要下单打样。

## 第四阶段：打板验证

PCB文件确认无误后，就可以导出Gerber文件下单打样了。推荐使用嘉立创（新用户有免费打样额度，正常下单也很便宜，几天就能到货）。

打板之前，建议用Gerber查看器（嘉立创自带、或者第三方工具均可）再检查一遍每一层的内容，确认层选择正确、丝印完整、钻孔无遗漏，避免因低级失误浪费一次打样机会。

拿到板子之后，不要急着焊元件。先做以下检查：

- **目视检查板子本身**：有无明显划伤、过孔是否通透、焊盘是否完整、阻焊层是否正常。
- **万用表蜂鸣档测电源和地**：确认没有短路，板子本身没问题再开始焊接。

第一次画板大概率会有问题，改版是完全正常的事。不要因为板子出了问题就气馁，每改一版，你对PCB设计的理解都会有实质性的提升。养成版本管理的习惯，每版工程文件单独保存，板子丝印上标注版本号（V1.0、V1.1……），方便复盘每次改了什么。

## PCB 设计要点

### 1. 铺铜与接地

- 无论数字地还是功率地，都需要打过孔连接上下两层地平面。
- 电源地铺铜：建议将连接方式改为直连，导电性和散热性更好。直连会导致焊接不易，可将热焊盘辐条宽度改为20mil作为折中方案。大功率电源走线同理，尽量直连或增加导线宽度。数字地铺铜：保持默认设置即可。
- 铺铜的范围应覆盖整个板面，不要只在局部铺铜。孤立的铜皮（即没有任何网络连接的铜皮）容易产生天线效应，干扰信号，应在DRC后检查并删除或连接。
- 地平面的完整性非常重要，不要在地平面上随意走信号线将地平面切断，这会破坏地平面的连续性，导致回流路径变长，EMC变差，高速信号完整性也会受影响。
- 过孔的数量要足够：铺铜与地平面之间的过孔越多，电阻越小，散热越好。建议在大面积铺铜区域均匀分布过孔，间距不超过300mil为宜。

### 2. 禁止区域

| 位置 | 规则 |
|---|---|
| 晶振下方 | 禁止铺地、禁止放置其他器件、禁止走非晶振导线 |
| 功率电感下方 | 禁止铺地、禁止走信号线（电感磁场会干扰信号） |
| 高速信号线下方 | 地平面应尽量保持完整，不要有过孔或其他信号线穿过，否则会破坏参考平面，影响信号完整性 |
| 敏感模拟信号周围 | 应设置禁止区域，避免数字信号线或高频时钟线从旁边经过，减少串扰 |

### 3. 晶振布局

- 晶振周围包地处理，使用粗线相连，过孔均匀分布。禁止区域从单片机引脚开始划定。
- 晶振信号为差分对信号，两根信号线应尽量等长。
- 晶振的负载电容（通常是两个十几pF的电容）应尽量靠近晶振本身摆放，走线尽量短，减少寄生电容的影响。负载电容的接地过孔应就近打到地平面，不要绕远。
- 无源晶振（需要外接负载电容）和有源晶振（内部已集成振荡电路，直接输出时钟信号）的布局要求略有不同。有源晶振对电源去耦要求更高，建议在电源引脚旁边放置100nF和10uF各一个电容。

### 4. 导线宽度

不同铜厚、导线宽度的载流能力不同，载流能力不足会导致电路无法正常工作或板子异常发热。

- **计算工具**：微信公众号「嘉立创EDA」→ 实用工具 → 电子硬件助手 → PCB走线宽度计算
- 计算时将温升控制在30°C左右即可。

注意：导线载流能力与电压无关，3.3V/1A 和 12V/1A 所需线宽相同。一般只在大功率用电器（电机、舵机、树莓派供电等）时需要计算线宽，普通信号线10mil即可。

### 5. 过孔载流

过孔的载流能力也需要注意。大电流路径上如果必须经过过孔，需要适当增加过孔的数量或孔径。单个标准过孔（内径0.3mm、外径0.6mm）的载流能力大约在0.5A到1A左右，具体数值与铜厚和温升有关，大电流时建议并联多个过孔。

对于需要通过大电流的走线，除了加宽导线，还可以在导线上方覆盖焊锡（即开窗处理，去掉阻焊层），增加实际导线的截面积，进一步提高载流能力和降低阻抗。

## 学习建议

对于电控方向来说，不需要把硬件电路研究得非常透彻，能看懂原理图、理解基本的电路模块功能，在大多数项目中已经够用了。电路设计通常有专门的硬件岗位负责，但在实验室阶段或进入小公司，往往需要从画板、焊接到调试全流程自己上手，所以掌握基本的PCB设计能力是有必要的。

## 小节总结

电路设计的核心价值，在于帮助你把系统结构真正看清楚。会看原理图，你才能知道电源是怎么分配的、信号是怎么流动的、某个模块为什么这样连接；会画PCB，你才算真正理解了一个硬件系统是如何从"电路图"变成"实物板子"的。

对电控来说，硬件不只是代码运行的载体，它本身就是系统的一部分。很多调试问题，表面上像软件bug，根源其实可能是供电、布线、采样或接口连接出了问题。所以学电路设计，不只是为了画板，更是为了在做项目时具备完整理解系统和分析问题的能力。
