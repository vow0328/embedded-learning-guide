# 10.3 原理图与 PCB 设计

> **前置知识**：[10.1 电路与电子技术基础](01-电路与电子技术基础.md) · [10.2 电源设计](02-电源设计.md)
> **掌握标准**：能独立完成一块两层板的原理图和 PCB 设计，知道布局布线的基本规则和常见错误
> **对应岗位**：硬件工程师 · 嵌入式软件工程师（需要自己做板时）· 电源工程师
> **练手建议**：把你做过的某个模块（比如一块最小系统板或一个传感器转接板）从原理图开始画一遍，导出 Gerber 打样，焊出来点亮

很多人对硬件设计有一种错觉，觉得门槛在"电路原理"上——要会算、会仿真、会分析环路。实际上，把一块常规的两层板从想法做到能点亮，**主要的工作量在流程和规矩上**，不在数学上。原理图怎么组织、封装怎么选、电源怎么走、地怎么铺、下单前查什么，这些事决定了你的第一版板子能不能一次跑通。

这一篇讲的就是这套流程和规矩。电路原理部分见 [10.1](01-电路与电子技术基础.md)，电源拓扑见 [10.2](02-电源设计.md)，本篇只讲"怎么把它画出来、做出来"。

## 从需求到打样：一条完整的流程

```mermaid
flowchart LR
    A[需求：板子要做什么] --> B[选型：芯片/接口/封装]
    B --> C[原理图：分模块绘制]
    C --> D[ERC 检查 + 建封装 + 出 BOM]
    D --> E[网表导入 PCB]
    E --> F[布局：定接口→分区→摆件]
    F --> G[布线：电源→地→信号→差分]
    G --> H[铺铜 + DRC + 检查清单]
    H --> I[导出 Gerber/钻孔/坐标]
    I --> J[打样 → 焊接 → 上电验证]
```

这条链上**越靠前的地方改起来越便宜**。在原理图阶段发现封装选错，改一个符号就完事；等 PCB 画完、板子打回来发现封装不对，代价是一周时间和一次打样费用。所以流程的意义不是"规范"，是**把错误尽量往前赶**。

## 原理图：把电路讲清楚

### 先看懂，再动手画

画之前先要有"读懂别人的图"的能力。**最合适的起点是一块单片机最小系统板的原理图**——它足够小，但把最基础的几个模块全包含了：

- **电源部分**：LDO 或者 DC-DC 降压电路，以及各路电源的去向。
- **晶振电路**：无源晶振加两个负载电容，或者有源晶振。
- **复位电路**：上拉电阻加电容，或者专用复位芯片。
- **BOOT 选择电路**：跳线帽或者电阻选择启动方式。
- **下载调试接口**：SWD 或者 JTAG 的连接器。

先搞清楚每个模块"负责什么"，而不是一上来就纠结内部工作细节。这一步的目标是看到一块板子时，脑子里能自动把它拆成这几块。

同时要学会查**数据手册**。它是每个元器件最权威的参考资料，重点看三个部分：

1. **引脚定义**：每个引脚是干什么的、哪些是电源脚、哪些必须接。
2. **推荐应用电路**：厂商给的典型连接方式，照着画基本八九不离十。
3. **电气参数**：工作电压范围、最大电流、逻辑电平。这三项决定你的电平和接口设计能不能对上。

一开始看不懂很正常，多看几次就会习惯那种排版和表述方式。这是硬件工程师最核心的一项基本功。

**读图之后一定要对照实物。** 找一块现成的开发板，边看原理图边在板上找到对应的元件——电源指示灯、晶振、复位键、USB 接口——把图上的符号和板上的实物一一对上。这种方式比单纯看图快得多，也是把抽象变具体的最短路径。

### 分模块画，别摊成一整张

画原理图的第一原则是**电源优先**。先把电源架构搞清楚：输入电压是多少、经过哪一级降压、产生几路电源、每路供给谁。电源没错，后面才有意义；电源画错了，信号部分画得再漂亮也是白搭。

其次是**分模块组织**。电路规模一大，就把功能相关的部分收进独立的子图（电源模块、主控模块、通信模块、驱动模块），顶层只保留模块之间的接口关系，这就是层次化原理图。好处是结构清晰，出问题时能快速定位到是哪一块。规模小的时候，在一张图上用分隔线划出功能区也能达到类似效果。

### 网络标号：原理图的"连线语言"

**网络标号（Net Label）是原理图里最重要的一个概念。** 很多原理图并不把所有连线都画出来，而是用 VCC、GND、USART1_TX 这样的标号表示连接关系——两个标号同名，就表示这两处是连在一起的。

看懂网络标号，才能真正理解信号的流向。自己画图时也要靠它：与其把线拉得满图都是、绕来绕去，不如就近打一个标号。**新手最容易犯的错是"把所有线都画出来"，结果图面像蜘蛛网，自己都读不懂。**

命名要有统一的规矩。电源用 VCC_3V3、VCC_5V 这样带电压的写法，信号用 模块_功能_方向 的写法（如 USART1_TX、MOTOR_PWM_L），不要出现 net1、net2 这种没人看得懂的名字。

### 电源符号与去耦电容

**去耦电容不能省。** 每个芯片的 VCC 引脚旁边都要放一个 100nF 的去耦电容，这不是形式，是真的有用：高频噪声会从电源引脚进入芯片，去耦电容的作用就是就近把这些噪声旁路到地，保证芯片供电稳定。多电源引脚的芯片，每个电源脚都要配一个。

电源符号（VCC 符号、GND 符号）的作用是让图面干净：同一网络到处画一根线到电源汇流点，图会乱得没法看。用符号代替，读图的人一看就明白。

### 命名与注释要规范

每个元器件都必须有明确的**位号**（R1、C3、U2）和**参数标注**（100nF、10kΩ、具体的芯片型号）。位号是焊接和调试时定位的唯一依据——"第三排左边那颗电容"这种描述在调试时毫无用处。

关键的地方随手加一行文字注释，比如"此处 10k 上拉，硬件 I2C 必需""该电阻决定限流点，改动前先看 10.2"。三个月后回来改板，你会感谢自己。

### ERC 检查

画完必须跑一次 **ERC（电气规则检查）**。它会揪出这些常见问题：输出脚和输出脚直接相连、电源网络被短路、有输入脚悬空、单点网络（某个网络只有一根线连着，多半是忘了接）。

ERC 的报错要一条条看，**不要"全部忽略"了事**。有些报错确实是误报，但大部分时候它指出的是真问题——而且是在画 PCB 之前就发现的真问题，这比板子回来再改便宜得多。

**可读性比美观重要。** 一张配色漂亮但读不出信号流向的图，价值远低于一张朴素但分块清楚、标注完整的图。

## BOM 与封装：最低级的错误最致命

**封装选错是硬件设计里最低级、也最常见的错误。** 它的表现极其惨烈：板子回来了，芯片焊不上去——不是引脚太密，就是焊盘少了一圈，整批板子报废，只能重新打一次。而它本来完全可以在画原理图的时候避免。

定义封装时记住三件事：

1. **封装名里的数字是尺寸，不是编号。** 0603 指的是 0.06 英寸 × 0.03 英寸（约 1.6mm × 0.8mm）的贴片尺寸，不是"型号 603"。同一颗阻容有 0402、0603、0805、1206 多种封装可选，选哪个取决于你的工艺能力和手工焊接需求。
2. **引脚间距（pitch）必须和数据手册一致。** 0.5mm 间距和 0.65mm 间距的封装不能互换，芯片一样也不行。
3. **贴片还是插件、有没有散热焊盘、方向有没有要求**，都要在封装里体现出来。

封装的来源通常有三个：

| 来源 | 优点 | 风险 |
|---|---|---|
| **EDA 软件自带库** | 覆盖常用元件，直接可用 | 冷门元件找不到；个别库参数有误 |
| **厂商/第三方库** | 器件厂商或社区维护，专业度高 | 版本杂乱，来源不明时不可信 |
| **自己画** | 100% 可控，能和数据手册严格对照 | 需要仔细核对，画错就是整批报废 |

**自己画封装是必修技能，不是进阶技能。** 冷门元件、国产替代型号、厂商自研芯片，几乎一定会遇到库里没有的情况。画封装时**对着数据手册的封装图逐个尺寸核对**，尤其是引脚间距、焊盘长度宽度、散热焊盘尺寸——这三项错一个，板子就废了。

BOM 是从原理图导出的一张"买什么料、买多少颗"的表。导出后要检查封装字段有没有和 PCB 库同源、位号有没有缺漏。BOM 的完整方法论（物料编码、替代料、量产字段）见 [10.6 打样量产与国产替代](06-打样量产与国产替代.md)。

## PCB 布局：先定边界，再摆器件

布局决定了布线的难度，布线决定了板子的性能，而**布局错了，再怎么布线都救不回来**。所以宁可多花时间摆件，也不要急着走线。

### 定接口和结构，是第一件事

板子的外形尺寸、固定孔的位置和直径、连接器的朝向和位置，这些必须**提前和结构侧确认**。接口位置定不下来，器件摆得再好也要推翻重来。

安装孔周围要留足够的铜皮间距（安装孔通常是金属孔，或者固定螺丝是金属的），否则螺丝一拧紧就可能把铜皮压到短路。定位孔、连接器开孔这些位置也要在 PCB 上如实标出来，避免装配时干涉。

### 按功能分区，模拟数字分开

- **模拟区和数字区分开**：ADC 采样、基准、运放这些模拟部分，和单片机的时钟、通信线、开关电源的开关回路离得越远越好。数字信号的边沿是干扰源。
- **大电流路径要短、要宽**：电源入口、电机驱动、功率回路，走线尽量短粗。
- **大电流路径要远离敏感信号线**：大电流回路是主要的磁场干扰源，别让它贴着 ADC 采样线或者晶振跑。
- **电源模块单独成区**：开关电源的输入回路（高频电流环路）面积越小越好，输出和输入分开，反馈走线要短并远离电感。

### 几个必须遵守的摆放规则

- **去耦电容紧贴引脚。** 100nF 去耦电容离引脚越近越好，**电容到引脚的那一小段走线本身就带电感，隔远了等于白放**。正确做法是电容和引脚在同一条短路上，过孔就近打到地平面。
- **晶振靠芯片，负载电容靠晶振。** 晶振离单片机引脚越近越好，两个负载电容（通常是十几 pF 量级）紧贴晶振摆放，走线尽量短，减少寄生电容影响。
- **晶振周围包地处理**：用粗线相连，过孔均匀分布，禁止区域从单片机引脚处就开始划。
- **晶振的两根信号线等效于差分对，要尽量等长**，长度差越小越好。
- **无源晶振和有源晶振的要求不同**：无源晶振靠负载电容起振，重点在电容和走线；有源晶振内部已有振荡电路、直接输出时钟，对电源去耦要求更高，**建议在电源引脚旁放 100nF 和 10uF 各一颗**。

### 禁止区域

有些地方必须留空，这是新手最容易忽略的一类规则：

| 位置 | 规则 |
|---|---|
| **晶振下方** | 禁止铺地、禁止放置其他器件、禁止走非晶振的导线 |
| **功率电感下方** | 禁止铺地、禁止走信号线（电感的磁场会干扰信号） |
| **高速信号线下方** | 参考地平面应保持完整，不要有过孔或其他信号线穿过，否则参考平面被破坏，信号完整性变差 |
| **敏感模拟信号周围** | 设置禁止区域，避免数字信号线或高频时钟线从旁边经过，减少串扰 |

这几条属于经验规则。它们背后的原理（回流路径、参考平面、磁场耦合）在 [10.5 信号完整性与 EMC](05-信号完整性与EMC.md) 里有展开，眼下先照着做就够用了。

## 布线：电源、地、信号、差分

布线的顺序建议是**先电源、再地、后信号、最后差分和特殊网络**。电源和地是板子的骨架，它们定下来之后，信号的通道自然就清楚了。

### 线宽与载流

**线宽不是拍脑袋定的，是按电流算的。**

- **普通信号线** 10 mil 左右就够（1 mil = 0.0254 mm）。
- **电源线** 建议不低于 20 mil，大电流路径要按电流单独计算。
- 不同铜厚、不同线宽能承载的电流不同。**载流能力不足的后果是板子异常发热，甚至烧断走线。**
- 计算工具可以直接用现成的：嘉立创 EDA 的公众号里有"实用工具 → 电子硬件助手 → PCB 走线宽度计算"，输入电流、铜厚和允许温升就能得到线宽。**计算时把温升控制在 30℃ 左右是一个常用的折中**，温升要求越严，需要的线就越宽。
- **注意：导线载流能力和电压无关。** 3.3V/1A 和 12V/1A 需要的线宽是一样的，因为发热只取决于电流。
- 实际经验是：**只有大功率负载（电机、舵机、大电流供电支路）才需要认真算线宽**，普通信号线 10 mil 即可，不必过度设计。

### 过孔载流

大电流路径上如果必须换层，过孔就成了瓶颈。**单个标准过孔（内径 0.3mm、外径 0.6mm）的载流能力大约在 0.5A 到 1A 之间，具体数值与铜厚和温升有关**（以厂商的工艺参数为准）。所以：

- 大电流路径上不要只放一个过孔，**并联多个过孔**，电流会被分摊。
- 需要更大载流能力时，还可以在走线上**开窗**（去掉阻焊层、露出铜皮）然后覆锡，用焊锡增加实际截面积，同时降低阻抗。

### 铺铜与接地

**铺铜是 PCB 设计的标配操作**，不是"高级技巧"。它能降低地阻抗、改善 EMC、帮助散热。几个要点：

- **无论数字地还是功率地，都要打过孔连接上下两层地平面。** 铺了铜却过孔稀疏，等于没铺。
- **过孔数量要足够**：铺铜与地平面之间的过孔越多，电阻越小、散热越好。大面积铺铜区域应**均匀分布过孔，间距不超过 300 mil**（约 7.6mm）为宜。
- **电源地铺铜的连接方式**：建议改成**直连**，导电性和散热性都更好。直连会让手工焊接困难（热量被铜皮迅速带走），折中方案是把热焊盘的辐条宽度改到 20 mil 左右。大功率电源走线同理，尽量直连或加宽。
- **数字地铺铜保持默认设置即可**，热焊盘辐条能在回流焊时起到平衡热量的作用。
- **铺铜范围应覆盖整个板面**，不要只局部铺。孤立的铜皮（没连到任何网络的铜皮）会产生天线效应、干扰信号，**DRC 之后要专门检查并删除或连上**。
- **地平面的完整性非常重要。** 不要在地平面上随意走信号线把它切断——地平面一断，回流路径就变长，EMC 变差，高速信号的完整性也跟着受损。

### 其他布线规则

- **避免直角走线。** 直角处会带来阻抗突变，高频下表现为反射。用 45 度斜线或者圆弧过渡。
- **回流路径要短。** 每根信号线的高频回流电流都会走它正下方的地平面，所以信号线下方的地必须连续——这也解释了"高速信号线下方禁止走线"这条规则。
- 走线尽量短、尽量少换层；换层就意味着回流路径要跨过地平面，需要就近放一个地过孔给回流电流"过桥"。

## 检查清单：下单前必须过一遍

板子画完，导出之前按这份清单逐项确认：

| 检查项 | 具体看什么 |
|---|---|
| **网络** | DRC 报错清零。重点看未连接的网络、单点网络、短路。**DRC 不清零不要下单。** |
| **间距** | 线到线、线到焊盘、焊盘到板边的间距是否满足工艺能力（具体值以打板厂的能力表为准） |
| **丝印** | 位号是否齐全、有没有被器件压住、极性方向（电解电容正极、二极管方向、连接器 1 脚）有没有标、接口引脚定义有没有写 |
| **装配干涉** | 器件之间有没有物理重叠、高器件会不会顶到外壳、连接器插拔方向有没有被挡、安装孔周围铜皮间距够不够 |
| **测试点** | 关键电源、地、通信线、烧录口有没有留出可探针或可焊接的测试点。**这一项最容易被忘，调试时最痛** |
| **板框与安装孔** | 外形尺寸、孔径、孔位是否与结构确认过 |
| **过孔与铺铜** | 过孔间距是否均匀、有没有孤立铜皮 |

## 导出与打样

设计确认后就导出生产文件。**Gerber 是光绘文件**，定义每一层的铜箔、阻焊、丝印图形；同时还要导出**钻孔文件**（所有过孔和安装孔的坐标与孔径）。

下单前建议用 Gerber 查看器再逐层看一遍（打板厂的下单页面通常自带，也可以用第三方工具）：**确认层选择正确、镜像没搞反、丝印没压焊盘、钻孔无遗漏**。一个低级失误就浪费一次打样。

批量生产时还会涉及**拼板**（把多块小板拼成一张大板，提高贴片和过炉效率），以及坐标文件、装配图、钢网文件等一整套资料——这些内容和下单流程在 [10.6 打样量产与国产替代](06-打样量产与国产替代.md) 里有详细说明。

**拿到板子之后不要急着焊。** 先做两件事：

1. **目视检查板子本身**：有没有明显划伤、过孔是否通透、焊盘是否完整、阻焊层是否正常。
2. **用万用表蜂鸣档测电源和地之间是否短路**。这一步只花几秒钟，但能救回一块板子和一堆芯片。确认板子本身没问题，再开始焊接（焊接与返修的完整内容见 [10.4 焊接与返修](04-焊接与返修.md)）。

最后是**版本管理**：每一版工程文件单独保存，板子丝印上标出版本号（V1.0、V1.1……）。第一次画板大概率会有问题，改版是完全正常的事——**每改一版，你对 PCB 设计的理解都会有实质性的提升，前提是你知道这一版改了什么。**

## 常见新手错误

| 错误 | 后果 | 怎么避免 |
|---|---|---|
| **封装选错** | 器件焊不上去，整批板子报废 | 建封装时对着数据手册逐个尺寸核对 |
| **去耦电容摆得太远** | 芯片偶发复位、ADC 读数跳动 | 100nF 紧贴引脚，过孔就近落地 |
| **电源线太细** | 板子发热、压降大、工作不稳 | 按电流算线宽，电源线不低于 20 mil |
| **铺了铜但过孔太少** | 地阻抗高，等于没铺 | 大面积铺铜区均匀打过孔，间距 ≤ 300 mil |
| **地平面被信号线切断** | 回流路径变长，EMC 变差 | 地平面保持完整，信号绕行或用另一层 |
| **器件事先没摆好就布线** | 走线绕来绕去、干扰加剧，最后被迫重来 | 布局时间至少占一半，摆好再走线 |
| **丝印没标极性/位号** | 焊接时焊反、找元件靠猜 | 丝印标位号、极性、接口定义 |
| **没留测试点** | 调试时无处下探针，只能飞线 | 关键网络预留测试点 |
| **DRC 没清零就下单** | 板子回来发现有网络没连上 | DRC 报错逐条处理，清零再导出 |
| **改版没做版本管理** | 分不清手上这块板是哪一版，无法复盘 | 工程文件分版保存，丝印标版本号 |

## 学习建议

1. **先看懂再动手，顺序不要跳。** 拿一块最小系统板的原理图，把电源、晶振、复位、BOOT、SWD 这五个模块逐个弄明白，再开始画。跳过这一步直接画板，等于闭着眼睛走路。
2. **EDA 工具选一个就够，别纠结。** 立创 EDA 国产、免费、上手快，元器件库丰富，下单直接对接打板厂，全流程无缝衔接，**强烈推荐作为第一款工具**；Altium Designer 是行业标准，功能强大、适合复杂项目和团队协作，但学习曲线陡，建议有基础后再上手；KiCad 开源免费，在国外的开源社区里用得很广，有兴趣可以了解。工具之间可以迁移，先学会"怎么设计"比先选对工具重要得多。
3. **第一个练手项目要小。** 画一块最小系统板，或者一个传感器转接板、一个电机驱动模块（如 TB6612 一类的驱动板，**型号仅作类型举例**）——目标是走完整条流程：原理图 → 封装 → 布局 → 布线 → DRC → 导出 → 打样 → 焊接 → 点亮。
4. **布局的时间要花够。** 新手最容易犯的错是"摆得差不多就开始走线"，结果走不下去又回来重摆。**布局决定了布线的难度**，多摆半小时能省两小时。
5. **每个项目结束都做一次复盘。** 这一版哪里出了问题、是原理图阶段就能避免的还是布局造成的、下次怎么改。改版不可怕，可怕的是每次都犯同一个错。
6. **不必把硬件研究到很深。** 对嵌入式软件方向来说，能看懂原理图、能画两层板、能判断问题出在软件还是硬件，在大多数项目里已经够用。真正的高速设计、电源设计、EMC 整改，有专门的岗位负责，也有对应的篇目可以深入。网上的免费入门教程很多（搜索"零基础 PCB 设计 + 立创 EDA"就能找到整套的全程教学），跟着完整做一遍比自己摸索快得多。

如果你想要一份现成的视频资源，下面两个是社区里流传较广、评价稳定的全程教学。分 P 数和时长是本文撰写时从 B 站查到的，会随作者更新而变化：

## 小节总结

原理图与 PCB 设计这件事，门槛不在电路理论而在流程和规矩。**大部分"板子回来跑不起来"的事故，根因都在几个反复出现的低级错误上**：封装选错、去耦电容摆远、电源线太细、地平面被切断、DRC 没清零。这些不是能力问题，是习惯问题——照着清单走一遍，就能避开八成。

原理图阶段最重要的事是把结构讲清楚：电源优先、分模块组织、靠网络标号而不是拉线表达连接、位号参数标注齐全、ERC 报错逐条处理。**可读性比美观重要**，一张能让人看懂信号流向的图才是好图。数据手册是这一切的依据，学会查引脚定义、推荐电路和电气参数，是硬件工程师最核心的基本功。

布局决定布线，布线决定性能。定接口和结构是第一件事，然后按功能分区、模拟数字分开、大电流路径短粗并远离敏感信号。几条硬规则要背下来：去耦电容紧贴引脚、晶振靠芯片且负载电容靠晶振、晶振和功率电感下方禁止铺铜和走线、高速信号线下方地平面保持完整。

布线的核心是电流和回流：线宽按电流算（只有大功率路径才需要认真算）、大电流路径上的过孔要并联、铺铜必须配足够密的地过孔、地平面绝不能随便切断。过孔、开窗加锡、差分对等长这些手段，都是在为电流和信号找一条更好的路。

最后，检查清单和版本管理是两个"不花钱但救命"的习惯。下单前把网络、间距、丝印、装配干涉、测试点逐项过一遍；每一版板子都标清楚的版本号并单独保存。**第一次画板有问题不是失败，是必然——真正浪费的不是打样的钱，是改完之后不知道自己改对了什么。**
