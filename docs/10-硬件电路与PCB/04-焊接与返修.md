# 10.4 焊接与返修

> **前置知识**：[10.2 原理图与 PCB 设计](02-原理图与PCB设计.md)
>
> **掌握标准**：能手工焊接常见的贴片和插件元件，能判断并处理虚焊、短路、立碑这些常见焊接缺陷
>
> **对应岗位**：硬件工程师 · 嵌入式软件工程师（开发阶段要自己改板）
>
> **练手建议**：找一块废板和一堆元件，练三种封装：0805 电阻、LQFP 芯片、QFN 芯片。练到能焊 QFN 不连锡，你的手工能力就够用了

再好的电路设计，焊不好就是废铁；再精密的芯片，一个虚焊就能让你调试到怀疑人生。焊接是一门纯手艺活，**理论部分一页纸就讲完了，剩下的全靠手熟**。

对嵌入式方向来说，这项技能的必要性取决于你的处境：在大公司里，焊接有专门的产线或工艺工程师负责；但在小团队、创业公司、以及所有的开发验证阶段，"自己改板、自己飞线、自己换料"是常态。**能自己焊，你的调试速度会比"等焊接师傅明天来"快一个量级。**

## 工具与耗材

一把烙铁加一卷锡丝就能开始，但工具的质量直接决定你的学习曲线。下面这些按重要性排：

| 工具 | 作用 | 选择建议 |
|---|---|---|
| **恒温电烙铁** | 主力的焊接工具 | 必买恒温的，温度设在 **320~360℃**（典型型号如白光 T12、SH72 一类，**仅作类型举例**）。那种几十块钱的定温烙铁温度不稳，焊出来全是虚焊，**别用它学焊接** |
| **焊锡丝** | 焊料 | **0.8mm 有铅、含松香芯**的最适合新手。有铅比无铅好焊很多，别跟自己过不去 |
| **助焊剂 / 松香** | 帮助焊锡流动、减少虚焊 | 涂在焊盘或引脚上，焊锡会明显"听话"很多 |
| **热风枪** | 焊拆贴片元件，尤其是 QFP、QFN | **没有热风枪基本焊不了密脚芯片**，属于必备 |
| **加热台** | 和热风枪类似，用于整板预热或焊接 | 好处是器件不会在吹风时被吹跑、不易错位 |
| **吸锡带 / 吸锡器** | 返工、清除多余焊锡 | 必备。桥连和拆元件全靠它 |
| **镊子** | 夹取贴片元件 | 买**尖头防静电镊子**，手感差别很大 |

条件实在受限时，可以先用便宜的烙铁在洞洞板上练手感，但**做实际项目时一定要换恒温烙铁**——用不稳定温度的工具练习，练出来的是坏习惯。

## 手工焊接：从直插到密脚芯片

### 直插元件：最简单，但方法要对

流程是：元器件引脚穿过 PCB 孔 → 翻到背面 → 烙铁尖同时接触**引脚和焊盘** → 送锡 → 等焊锡润湿焊盘形成锥形 → 撤烙铁。

关键在于**先加热、后送锡**：用烙铁同时加热焊盘和引脚大约 2 秒，再把焊锡送到焊点上。**不要把焊锡直接怼到烙铁头上让它化**——那样焊锡没有经过被焊金属的加热过程，形成的是"粘"上去的锡，不是金属连接，看着焊上了，其实一碰就掉。

送锡的正确姿势是：焊锡丝对着元器件引脚，烙铁在引脚另一侧，让焊锡慢慢向烙铁靠近。

### 贴片阻容（0805 / 0603 封装）

最实用的手法是"**先固定一端，再焊另一端**"：

1. 先用烙铁在一个焊盘上**预上一点锡**。
2. 用镊子夹住元件放到位置（预上锡的那一端对准）。
3. 烙铁融化预上的锡，把元件固定住。
4. 再焊另一端。**只要第一端固定好了，另一端不会跑。**

0402 及以下封装建议直接用**热风枪 + 锡膏**，手工一个一个焊非常折磨人。如果只有烙铁，至少要用质量好一点的锡丝，并且**控制温度和加热时间**——封装越小，焊盘越容易被热坏。

### 密脚芯片（QFP / LQFP 封装）

以常见的 LQFP 封装单片机（比如 STM32F103C8T6 一类的 48 脚封装，**型号仅作类型举例**）为例，靠"逐个引脚焊"几乎不可能，正确方法是**固定 + 拖焊**：

1. **先对准一个角**，把那个角的引脚焊住固定。
2. **再焊对角**，把第二个角固定。这样芯片的位置就锁死了。
3. **确认位置正确**——四个边的引脚都要压在自己的焊盘上，没有整体偏移。这一步没确认就往下焊，最后只能拆了重来。
4. 然后可以选择**逐个引脚焊接**（慢但稳），或者直接**拖焊**。

**拖焊技巧**：烙铁蘸上助焊剂，沿着引脚排列的方向轻轻拖过去，多余的焊锡会被带走，留在最后的引脚上或者被烙铁带走。**助焊剂是拖焊的关键**——没有它，锡会粘得到处都是。如果拖完发现桥连了，用吸锡带贴上去吸掉多余的那一条即可。

### QFN / BGA 封装：需要风枪和锡膏

QFN 和 BGA 的引脚在封装底部（QFN 在四周底部、BGA 在芯片下面的球阵列），**手焊几乎不可能**，需要锡膏配热风枪或者回流焊。建议的装备组合是：**钢网 + 锡膏 + 好镊子 + 加热台**，用钢网给焊盘印锡膏，放上元件，用加热台或风枪完成回流。

新手不必一开始就练 QFN——先把 0805 和 LQFP 焊熟。但要注意：现在很多芯片（尤其是电源管理、传感器、无线模块）出厂就是 QFN 封装，**长期做项目的话，这一关迟早要过。**

### 热风枪与回流温度的要点

用风枪的核心是"**均匀受热、够温但不超温**"：

- **风量调小、温度够用即可。** 风量太大，小元件会被直接吹跑；温度太高或加热太久，封装会分层、塑封会起泡。
- **绕圈移动，不要盯着一个点吹。** 让整块区域均匀升温，而不是局部过热。
- **焊锡熔化（焊点变成亮银色、能流动）之后就停止加热**，让板子自然冷却，不要用风去吹凉。
- **整板预热**（用加热台打底）能显著降低风枪需要的温度，对器件更友好。

**一个必须记住的原则：反复加热是器件和焊盘最大的敌人。** 同一个焊点不要来回折腾三五次；拆焊前先把所有引脚都加热到锡熔化再取，而不是硬撬。

## 焊接缺陷：怎么判断、怎么处理

这是实操中最实用的一张表。看到"焊得不对"，先对照这张表判断是哪一类，再按对应的方法处理。

| 缺陷 | 表现 | 原因 | 处理 |
|---|---|---|---|
| **虚焊** | 焊点看起来完整，实际焊锡和焊盘或引脚之间没有形成金属连接 | 温度不够、加热时间太短、焊盘氧化 | 重新加热焊点，加少量新焊锡和助焊剂，确保焊锡完全润湿焊盘和引脚 |
| **冷焊** | 焊点表面粗糙、呈颗粒状、没有光泽 | 焊锡在凝固过程中板子或元件发生了抖动 | 重新加热让焊锡完全熔化，然后**保持不动、自然冷却** |
| **桥连 / 短路** | 相邻两个焊点被多余的锡连在一起 | 锡量过多、拖焊时锡没带干净 | 用吸锡带吸走多余的锡，配合助焊剂效果更好 |
| **立碑** | 贴片阻容一端焊住、另一端翘起来立着，像一块碑 | 两端受热不均——一端先熔、先凝固，把元件拉了起来 | 加热两端让锡同时熔化，用镊子压平；焊接时两端尽量同步加热，或先用风枪整体预热 |
| **偏移** | 元件没有对正焊盘，偏出一部分 | 贴装时没对准，或焊第一端时被拉偏 | 焊第一端前先对准；已经焊住的，加热那一端用镊子推正 |
| **锡珠 / 锡球** | 焊接时飞溅出来的小锡粒落在板面上 | 助焊剂涂得太多、受潮，或者锡丝含水汽 | 用镊子或毛刷清除。**锡珠可能造成短路，必须清干净**——助焊剂别涂太多可以减少飞溅 |
| **漏焊** | 该焊的引脚没焊 | 检查不仔细，尤其是芯片底部的引脚 | 目视逐脚对照，用放大镜或微距拍摄 |
| **焊盘脱落** | 焊盘从基板上剥离 | 过度加热，或者多次返工 | **不可逆的损伤。** 预防办法是控制温度和时间，**每次加热不超过 3~5 秒**，间隔冷却后再加热。脱落之后只能靠飞线补救 |

**虚焊是最值得花心思的一类。** 它的可怕之处在于"看不出问题"：目视检查完全正常，上电却时好时坏，或者温度一变就出问题。新手调试时遇到的"这板子时灵时不灵"，很大一部分就是虚焊。

## 返修：拆、清、补

改板、换料、救板，都靠返修。这是焊接里最考验手艺、也最有价值的一部分。

### 拆元件

- **密脚芯片（QFP/QFN）**：用热风枪绕圈吹，等所有引脚的锡都熔化后用镊子轻轻取下。**不要硬撬**——没熔就撬，焊盘一定跟着掉。
- **大功率器件、带散热焊盘的芯片**：需要整板预热或者用更大的风量，否则散热焊盘上的锡化不了。
- **直插元件**：可以用吸锡器逐个脚吸，或者加热后整排拔出。
- **拆下来的元件不要扔**（除非已经损坏）。贴片阻容是消耗品，芯片往往还可以重用。

### 清理焊盘

拆完必须把焊盘清干净，否则新元件放不平：

- **吸锡带**是主力：贴在焊盘上，烙铁压在上面加热，锡会被吸进带子里。
- 配合**助焊剂**用，清除效果会好很多。
- 清理完检查焊盘是否完整、有没有残留的锡珠。**残留的锡珠会在下次上电时变成短路。**

### 飞线与跳线修补

飞线是"用导线代替原本的走线"，是救板的核心手段：

- **用细漆包线**（比杜邦线细得多、也不容易挡住其他元件）。
- **走线要贴着板面**，用胶或者锡固定在几个点上，避免悬空被拉断。
- **飞线的两端要焊牢**：焊到芯片引脚上的，焊点要小而结实，不要让它压到旁边的引脚。

**跳线修补**适用于断线的情况：找到断开的两点——通常是两个过孔、两个元件焊盘，或者一个焊盘加一根走线——用一段导线连上。**修补之前先用万用表确认断开的位置**，不要凭感觉乱连。

### 焊盘掉了怎么救

焊盘脱落是不可逆的损伤，但通常还能救：

1. **判断是哪一段焊盘掉了**：是元件焊盘，还是焊盘连出去的那段走线。
2. **如果只是元件焊盘掉了**，但走线还在：把元件焊到走线露出来的那一段上，或者从引脚直接飞线到下一个连接点。
3. **如果焊盘连走线一起断了**：顺着原理图找到这个网络的另一个端点（下一个元件、过孔或者排针），**从元件引脚直接用细漆包线飞过去**。
4. **救回来之后要测通断**，用万用表确认这条网络真的连通了，而且没有和旁边的网络短路。

**判断值不值得救**：如果只是掉了一两个焊盘、网络清楚、飞线路径短，值得救；如果是一整片焊盘脱落、密脚芯片底下多个焊盘全掉，通常重新打样比反复折腾更省时间（见下文）。

## 检查方法：目视、万用表、上电

**焊完不要直接通电。** 按这个顺序检查：

1. **目视检查。** 用放大镜或者手机微距镜头逐个焊点看，重点找三类问题：**桥连**（两个引脚被锡连在一起）、**虚焊**（看着焊上了实际没连）、**漏焊**。合格的焊点应该像一个小小的光滑火山口，而不是圆滚滚的锡球或者发灰的粗糙面。
2. **万用表检查。** 用蜂鸣档测相邻引脚之间有没有短路，**重点是电源和地之间有没有短路——这一步上电前必查**。同时也可以测一测关键网络的通断，确认没有断线。
3. **上电测试。** 做法有两种：**先不插（或先不焊）芯片，只测电源部分的电压**是否正常（3.3V、5V 是否到位）；或者**焊一部分测一部分**，"分段验证"是更省事的办法。正常之后再上芯片，能避免"一上电就烧芯片"的悲剧。
4. **在线测量。** 上电后对照原理图逐个测关键节点的电压：芯片的 VCC 引脚、复位引脚的电平、晶振两端有没有起振（这一项需要示波器，方法见 [11.1 测量仪器](../11-工具仪器与仿真/01-测量仪器.md)）。这一步能验证各模块是否按预期工作，也是把"焊接问题"和"设计问题"区分开的关键。
5. **限流保护。** **第一次给一块新焊好的板子上电时，一定要用带限流功能的可调电源**，把限流设在预期电流的 1.5 倍左右。一旦有短路，电源会自动进入恒流状态，不至于直接把器件烧掉。条件不具备时，可以**串联一个小功率灯泡**（5W 左右）代替：短路时灯泡会亮、电流被限住，正常时灯泡几乎不亮。

## 安全：三件必须当心的事

焊接的危险不在于"难"，在于**它看起来不危险，所以新手会忽略防护**。

- **烫伤。** 烙铁头、热风枪出风口、刚焊完的元件和焊点，温度都在几百度。养成"**拿起烙铁就默认它是热的**"的习惯，用完立刻放回烙铁架，不要随手放在桌面上。风枪用完不要马上收，等出风口冷却。
- **烟雾。** 助焊剂受热会产生烟（松香烟尤其明显，长时间吸入对呼吸道不好）。**工作环境一定要通风**，有条件的用吸烟仪或者小风扇往外吹。不要凑近焊点去闻、去看。
- **静电。** 人体静电能打穿 MOS 管的栅极和一些敏感芯片。手拿芯片前**先摸一下接地的金属**放电；有条件就用防静电手环、防静电桌垫，芯片拆封后放在防静电袋里。冬天穿化纤衣服、走在地毯上，静电尤其容易积累。

## 什么时候该重新打样，而不是继续修

这是返修里最重要的一个判断，也是新手最容易做错的决定：**修不是目的，跑起来才是。**

出现下面这些情况，应该停下来重新打样：

- **整批板子都有同一个问题**（比如某个封装画错了）。修一块没意义，要么重新打样，要么让产线统一返修——但"手工改一百块板"的成本通常高于重开一版。
- **同一块板反复修、越修越糟**：焊盘一片一片掉、飞线越飞越多。这时候板子的可靠性已经不可信了，后面调试出的问题到底是设计问题还是修补引入的问题，你也分不清。
- **密脚芯片底下的焊盘脱落、多层板内层断线**。这类修复难度极高，成功率低，而且修好了也不可靠。
- **这一版本来就是个验证版**。如果目的只是验证原理，重开一版比抢救一天便宜得多——打样的钱和时间，往往小于你花在这上面的工时。

反过来，**值得修的典型场景**是：只有一两处小问题、网络清楚、飞线路径短、板子是最后一次改版或者已经生产了多块。这时候修板是更划算的选择。

**核心判断只有一条：把"修板的时间"和"重新打样的时间与成本"放在一起比。** 修一块板花两小时，值；修一天还修不通，不值。

## 学习建议

1. **按这个顺序练，一步一步来**：先在洞洞板上练直插焊接，熟悉烙铁的手感和送锡的节奏；再找一些废板或废旧电路板上的贴片元件练 0805 封装；然后挑战更小封装和更密的引脚间距（LQFP），最后是 QFN。**跳过前面的阶段直接练 QFN，挫败感会很强，也学不到正确的手法。**
2. **每焊完一次都要认真检查焊点质量。** 发现问题立刻纠正，**不要带着坏习惯继续练**——焊接是肌肉记忆，坏习惯比不会更麻烦。
3. **焊接的理论部分是这本教程里最少的，多焊两遍比多看两篇教程有用得多。** 与其到处找教程视频，不如买一块焊接练习板（或者拿一块废板 + 一包贴片阻容），反复焊、反复拆。**练到能焊 QFN 不连锡之后，剩下的只是速度问题。**
4. **助焊剂要舍得用。** 新手最常见的心理障碍是"助焊剂会不会腐蚀电路"——正常用量下，残留物远比虚焊的危害小。焊锡不听话的时候，第一反应应该是"再加点助焊剂"，而不是"再加热一会儿"。
5. **尽早养成两个动作**：焊完必用蜂鸣档测电源对地；第一次上电必用限流电源。这两个动作加起来不到一分钟，能省掉大量的芯片和板子。
6. **把焊接当成调试能力的一部分来练。** 会焊的人可以随手飞线、换料、断开某一级单独测试，排查问题的自由度完全不同。硬件跑通之后要做什么，见 [2.1 单片机平台选型](../02-MCU与体系结构/01-单片机平台选型.md)。

## 小节总结

焊接是一项纯手艺活，这一篇里需要"记住"的内容不多，需要"手熟"的内容不少。工具的选择上，恒温烙铁和含松香芯的有铅锡丝是新手最低的入门门槛，热风枪是密脚芯片的必备项，助焊剂、吸锡带、镊子三件耗材的投入回报比任何"技巧"都高。

三种封装的套路各不相同：**直插靠预热**（先加热焊盘和引脚，再送锡）、**贴片靠固定**（先焊一端定位，再焊另一端）、**密脚芯片靠拖焊**（助焊剂铺路，烙铁带着多余的锡走）。QFN 和 BGA 需要锡膏配风枪或加热台，是迟早要过的一关。

缺陷里最值得警惕的是虚焊——它目视看不出来，却能让板子时好时坏，是大量"灵异问题"的真正源头。桥连、冷焊、立碑、锡珠各有明确的表现和处理方法，对照表格就能判断。焊盘脱落不可逆，预防的关键是控制加热时间（每次不超过 3~5 秒），补救的手段是飞线。

焊完之后的检查顺序不能省：**目视找桥连和虚焊 → 万用表查相邻脚和电源对地短路 → 分段上电测电压 → 用限流电源做第一次上电**。这几步一共花不了几分钟，却能把"上电就烧"这种最贵的错误挡在门外。同时别忘了安全：烫伤、烟雾、静电，这三件事都是"不注意的时候才出事"。

最后是一个判断力问题：**不是所有板子都值得修**。整批性缺陷、反复修补、焊盘大面积脱落、多层板内层断线，这些都该果断重新打样。把修板的时间和重新打样的成本放在一起比，答案通常很清楚——焊接是为了让项目跑起来，不是为了让每一块废板都复活。
