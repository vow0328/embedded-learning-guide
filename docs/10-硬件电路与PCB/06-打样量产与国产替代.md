# 10.6 打样量产与国产替代

> **前置知识**：[10.5 信号完整性与 EMC](05-信号完整性与EMC.md)
>
> **掌握标准**：能说清一块板从"打样"走到"量产"中间要过哪些关，能整理出一份可以直接交给贴片厂的 BOM，并能对一个国产替代型号给出有依据、标明了不确定项的评估结论。
>
> **对应岗位**：嵌入式硬件 · 硬件测试与验证 · 全栈/小团队技术负责人 · 需要对接供应链的研发岗
>
> **练手建议**：挑一块你熟悉的板子，把它的 BOM 按"位号—料号—封装—关键参数—替代料—供货状态"六个字段整理成一张表，再挑其中一颗芯片，找出一个国产同类并列出迁移需要重新验证的清单。

上一篇讲的是怎么把 Gerber 导出来、怎么在嘉立创下单打样——那是"一个人把板子做出来"。这一篇讲的是另一件事：**怎么让这块板子被一千个人、一万个人用得上**。这里面几乎没有电路原理，全是流程、文件、成本和供货，也就是所谓"工作以后才知道"的部分。

## 打样、小批量、量产：三件不同的事

很多人以为它们的区别只是"数量"。真正的区别是**每一版改动的代价**。

| 阶段 | 典型数量 | 改一版板子的代价 | 关注点 |
|---|---|---|---|
| **手工打样** | 1~10 片 | 一个下午焊完，改版就是重新下单 | 能不能跑起来 |
| **小批量** | 几十~几百片 | 几千到几万元，加上贴片厂的排产时间 | 一致性：这批和上一批一样吗 |
| **量产** | 千片以上 | 重新开钢网、改产测治具、可能触发客户重新认证 | 良率、成本、供货和生命周期 |

打样阶段，板子能亮就算成功；量产阶段，"能亮"只是及格线，你还得回答：**第 500 片和第 1 片一样吗？换了一批芯片还一样吗？明年还买得到这颗料吗？** 新手最容易犯的错，就是把打样阶段的习惯带进量产——随手选的封装、随手填的 BOM 备注、随手改的参数，到了量产都会变成真金白银。这一篇大部分内容，本质上都是在讲怎么避免这种代价。

## 交给工厂的那一整套生产文件

Gerber 只是生产文件里的一份。一套完整的下单资料通常包括下面这些，**少一份，工厂就得回头找你一次，交期就往后拖**。

| 文件 | 作用 | 常见错误 |
|---|---|---|
| **Gerber** | 光绘文件，定义每一层的铜箔、阻焊、丝印图形 | 层选错（镜像、漏层）、丝印压焊盘、阻焊开窗太小 |
| **钻孔文件** | 所有过孔和安装孔的坐标、孔径 | 与 Gerber 未对齐、单位不一致（英制/公制混用） |
| **BOM（物料清单）** | 买什么料、多少颗 | 封装与 PCB 不符、参数缺失、位号对不上 |
| **坐标文件** | 每个位号在板上的 X/Y 坐标和旋转角度，贴片机靠它贴 | 原点没设对、角度与封装库基准不一致导致整批转 90 度 |
| **装配图** | 人看的图：哪位号在哪个位置、极性朝哪 | 缺极性标注、版本与当前板不一致 |
| **钢网文件** | 锡膏印刷用的模板开孔 | 与最新一版焊盘不同步——**改了焊盘忘了重开钢网** |

几个必须养成的习惯：

1. **所有文件用同一个原点。** PCB 原点、坐标文件原点、贴片厂默认原点对不上，就会出现"整批器件偏移两个焊盘"这种灾难。
2. **位号和封装从原理图一路传到 BOM，不要手工重打**——手工敲一遍 BOM 就等于引入一次错位机会。
3. **每个文件都带版本号。** 板子丝印写 V1.2，BOM 文件名也写 V1.2，钢网标签也写 V1.2。量产事故里，"用错了上一版文件"占比高得离谱。

## BOM 管理：量产里最容易出事的地方

BOM 看着就是一张表，实际上是硬件研发和采购、生产之间唯一的信息接口。表错一格，产线就停一次。

### 物料编码：为什么不能只写型号

小团队常直接用芯片型号当物料编号，比如"STM32F103C8T6"。这在只有几十种料时能用，一旦超过一两百种就会崩。**同一颗芯片的不同封装、不同温度等级、不同包装（编带/管装）是三个不同的物料**，如果编码里体现不出来，采购就会买错。

成熟一点的做法是给每种料一个内部编码，编码本身不带含义（纯流水号或按类别分段），型号、封装、温度等级、供应商都作为属性挂在编码下面。这样将来换供应商、换型号时，**改的是属性，不是编码**——已经发出去的 BOM、已经写好的作业指导书、已经做好的产测程序都不用动。

这一点对求职者很关键：面试里被问"怎么做 BOM 管理"，能答出"物料编码要和具体型号解耦"的人，比只会说"用 Excel 记一下"的人高一档。

### 位号与料号：两种对应关系必须分清

- **位号（如 R17、C8、U3）** 是"板上这个位置"，一个位号焊一颗料。
- **料号（如 RC0603FR-0710KL）** 是"仓库里这一盘料"，一个料号可以对应很多个位号。

同一种 10kΩ 电阻可能出现在 R1、R5、R17 三个位置——**这三个位号对应同一个料号，但 BOM 里要分三行写**。贴片机是按位号贴的，合并成一行会导致漏贴。反过来，采购是按料号汇总数量的，所以 BOM 工具通常需要同时给出"按位号展开"和"按料号汇总"两个视图。

### 替代料：为什么必须提前准备

替代料（第二供应商，Second Source）指的是同一个位置可以互换使用的另一个型号。它的价值不在平时，在**缺货的时候**：某个通用型号的交期突然从几周拉到几十周，所有用它的产品同时卡住——有替代料的设计，采购当天就能换；没有的，要重新画板、重新打样、重新验证，几周就没了。

准备替代料的原则：

1. **关键器件（单片机、电源芯片、接口芯片、存储器）必须有至少一个替代方案**，并在 BOM 里明确写出可替代关系和验证状态（已验证/待验证/仅引脚兼容）。
2. **替代料要提前验证，不要等到缺货才验**——缺货时是最没有时间做验证的时候。
3. **区分"可以直接换"和"要改板才能换"。** 前者是 pin-to-pin 且软件兼容，后者只是功能相当；两者写在同一列里，出事时会被误读。

### BOM 里最容易出错的字段

| 字段 | 出错后果 | 怎么防 |
|---|---|---|
| **封装** | 最严重。料买回来了，焊盘对不上，整批报废 | BOM 封装必须和 PCB 库同源，不能手填 |
| **精度** | 电阻用了 5% 代替 1%，采样电路误差直接超标 | 采样、分压、基准相关的位置明确写精度 |
| **耐压** | 电容耐压不够，上电就炸或寿命骤减 | 电源入口和开关节点上的电容标注耐压并留余量 |
| **温度等级** | 消费级（0~70℃）用在户外设备，冬天不启动 | 明确写工作温度范围，工业/车规件单独标注 |
| **极性器件方向** | 钽电容、电解电容、二极管、LED 反贴 | 装配图标注极性，BOM 里也写一句 |

一句话总结：**BOM 里没有"随便填填"的字段。** 每一个你认为不重要的格子，都是产线上某个人会照着执行的东西。

## SMT 贴片流程：封装选小了，钱就上去了

贴片的基本流程是：**钢网印刷锡膏 → 贴片机按坐标文件贴装 → 回流焊 → 检测**。板子先过钢网，锡膏通过开孔漏到焊盘上；贴片机把器件放上去；再整板过回流焊，锡膏熔化完成焊接。流程本身很简单，成本几乎全藏在细节里：

- **钢网是每种板子单独开的**，改一次焊盘就要重开一次。打样阶段改版频繁，钢网费用是笔隐形支出。
- **贴片机的贴装精度和速度，取决于最小的那个器件。** 板上只要有一颗 0201 或者 0.4mm 间距的 QFN，整块板就得用更高精度的机器、更慢的速度、更贵的工艺。**为了省一点布局面积，把某个电阻从 0603 换成 0201，可能让整块板的贴片单价上浮，还更容易出虚焊。**
- **双面贴装、混装插件（THT）会显著增加工序，密脚芯片（QFN/BGA）还要 X 光检查。** 能用单面贴片解决的不要为好看做成双面；能在贴片面解决的不要留插件件——插件基本要靠人工或波峰焊，贵且一致性差；密脚焊点目检看不出来，检测成本也要算进去。

对新手的直接建议：**打样阶段就用你量产时会用的封装，不要"先用小封装试试"。** 0603 及以上、引脚间距 0.5mm 及以上的封装，是绝大多数场景下成本和可靠性的最佳平衡点。真正需要小型化的产品，才值得为小封装付出成本和良率代价。

## 成本由什么决定

- **板层数与板尺寸**：这两项是板材成本的主项，层数越多、面积越大越贵。
- **器件数量与贴片点数**：贴片厂大多按"点"计价，双面板、插件点都更贵。
- **器件本身的采购价**：量小的时候，器件价钱甚至超过加工费。
- **起订量（MOQ）**：打样常常是"起订量决定了单价"，而不是需求数量。
- **特殊工艺与测试包装**：沉金/镀金、阻抗控制、盲埋孔、厚铜、超薄板，每一项都会跳一个档；飞针测试、测试架、编带、防静电包装也都要算钱。

**降本的正确顺序**是：先减器件数量，再减层数、缩面积，最后才去和供应商谈单价。一个能省掉十几颗器件、把四层降到两层的设计改动，降本幅度远大于在采购价上磨下来的几个点。

## 供货周期与生命周期

### 为什么有的芯片交期长达几十周

芯片从下单到交货，要排队经过晶圆制造、封装、测试几道产能受限的环节。一旦某个环节紧张（车规、工业、消费需求挤在同一条产线上），或者市场出现恐慌性备货，交期就会从几周拉长到十几周、几十周——**这是行业周期，不是某一家的问题**。

所以工程上有个习惯：**先看供货再选型。** 定方案时先查目标型号的库存和交期，再决定用它。听起来顺序反了，实际上是血泪教训——选了一颗性能完美但买不到的芯片，项目等于没做。另外要留意，**中间商手里的"现货"存在翻新料、拆机料风险**，量产时优先走正规代理；设计时也尽量选有多家供货的通用型号，避免被单一渠道卡住。

### 生命周期：停产（EOL）有多麻烦

芯片有生命周期。消费类芯片三五年更新一代很正常，工业和车规料的供货承诺会长一些（常见是十年量级，具体以厂商正式文件为准）。停产时厂商会发通知（通常叫 PCN/EOL 通知），给出**最后购买日期**，随之而来的是几件麻烦事：

- 要在最后购买日期之前，一次性把未来几年要用的量买回来——占用资金，还要考虑存储条件（湿度敏感器件要干燥保存，某些料有保存期限）。
- 或者选择改板换料——设计、打样、认证、产测治具全都要重来一遍；如果产品已经卖给客户，换料可能还需要通知客户并取得同意。

**这就是"选型要看长期供货"的真正含义**：不是怕买不到，是怕买不到的时候你要付的代价，远远超过当初省下的那点成本。

## 国产替代：为什么它成了刚需

过去几年，国产替代从"可以试试"变成了"必须准备"，原因有三条同时发生：**供货**——进口料的交期和价格波动太大，项目排期不能押在别人身上；**成本**——国产同类芯片在价格上有明显优势，尤其是通用型号；**供应链安全与政策**——很多行业（尤其涉及能源、工业、汽车）明确要求关键器件有国产选项或至少要有替代预案。

对求职者的意义很直接：**面试里问"你怎么选型""考虑过国产替代吗"的人越来越多**，能答出替代评估维度的人非常少。

### 国产单片机的格局

国产单片机的整体思路是**从兼容切入，再走出自己的产品线**。按和 STM32 的关系，大致是这样一个格局：

| 厂商 | 代表系列 | 与 STM32 的关系（需自行核实具体型号） |
|---|---|---|
| **兆易创新 GD32** | GD32F103/F303/F4 等 | 引脚与 STM32 同名系列高度对应，外设设计思路相似，是市场上最主流的国产替代路线之一 |
| **沁恒 CH32** | CH32F103、CH32V003/V307 等 | 部分型号与 STM32 引脚对应；同时有基于 RISC-V 内核的自研产品线，工具链和开发环境与 ARM 不同 |
| **极海半导体（Geehy）** | APM32 系列 | 官方明确主打与 STM32 的引脚兼容替代，并提供迁移文档 |
| **国民技术（Nations）** | N32 系列 | 以 Cortex-M4 产品对标 STM32F4 一类的中高端型号 |
| **华大/小华半导体** | HC32 系列 | 兼容与外设自研两条路线并行，在通用市场有较广泛使用 |

此外还有航顺、灵动微、中微半导体等一批厂商，各自在不同细分市场有份额。**上面这些对应关系只是大致格局，具体到某一颗型号能不能直接换，必须逐一核实**——同一个系列下的不同型号，兼容程度可能完全不同。

### 引脚兼容不等于软件兼容

这是国产替代里最重要的一句话，也是新人最容易吃亏的地方。引脚兼容（pin-to-pin）只意味着**板子不用改**，它完全不代表下面这些：

- **寄存器行为一致。** 相同功能的寄存器，位定义、默认值、复位值可能不同。
- **外设行为一致。** 同样的 SPI 配置，时序细节、FIFO 深度、错误标志的处理可能不一样；定时器的计数方式、ADC 的采样时间换算也可能不同。
- **电气参数一致。** 工作电压范围、IO 驱动能力、内部上拉阻值、上电复位阈值都可能不同。这一条最隐蔽——**板子能跑，但边界条件下会出问题**。
- **时钟体系一致。** 最高主频、Flash 等待周期、PLL 配置都可能不同，同一段延时程序在新芯片上时间就不对了。
- **库和工具一致。** 厂商会提供自己的库和 IDE，即使 API 名字一样，实现和坑也不一样。

所以真实的迁移工作量是：**改板（或确认不用改）+ 改驱动 + 重测时序 + 重测低功耗 + 重做 EMC 评估 + 重跑产测**。经验上，"直接换过去就能跑"的项目确实有，但那是验证出来的结果，不是可以假设的前提。

### 替代评估该看哪几个维度

拿到一个候选替代型号，建议按下面这张表过一遍，**每一条都要落到"谁验证、怎么验证、验完没有"**：

| 维度 | 要确认什么 |
|---|---|
| **引脚与封装** | 是否 pin-to-pin；封装尺寸、散热焊盘是否一致；贴片和钢网要不要重开 |
| **电气参数** | 供电范围、IO 电平与驱动能力、复位与上电时序、时钟要求 |
| **外设行为** | 逐个外设对照，重点是你真正用到的那几个；对照数据手册而非"听说兼容" |
| **勘误表（Errata）** | 替代型号有没有已知的设计缺陷，是否踩到你的用法上。这一步经常被跳过 |
| **功耗与低功耗模式** | 睡眠/停机/待机的实际电流和唤醒时间，电池产品必须实测 |
| **工具链与调试** | 下载调试器是否通用、开发环境、烧录方式（量产烧录尤其重要） |
| **生态与资料** | 参考手册、例程、中文资料、社区活跃度、RTOS 与中间件的现成移植 |
| **长期供货承诺** | 厂商对这颗料有没有供货年限承诺，是否收到过停产通知 |
| **认证与合规** | 车规（AEC-Q100 一类）、工规等级是否满足产品要求，是否影响已有的整机认证 |

### 替代的真实成本

替代的成本从来不是"换个型号"这四个字能概括的。它至少包括：**重新验证的人力时间**（把上面那张表走完）、**改板与打样费用**、**固件适配工作量**、**EMC 与可靠性复测**（产品做过认证的，还要评估变更是否触发重测）、**产线烧录工装与产测程序的调整**、**旧料清尾与新料备货的资金占用**，以及产品已出货时的**客户沟通成本**。判断建议是：**如果一颗芯片只是"便宜一点"，不要换。** 只有当它同时满足"供货更稳""有多家来源""长期供货有承诺"中的至少两条，迁移的成本才划得来。

### 电源、运放、接口、传感器的大致格局

- **电源**：这个方向的国产化已经相当普遍，矽力杰、圣邦微、南芯、杰华特、芯朋微等，DC-DC、LDO、充电管理等品类基本都有国产对应型号。
- **运放与模拟**：圣邦微、思瑞浦、润石等，通用运放和比较器已大量使用；高精度、低噪声、高速这类的国产型号也在补齐，但具体指标要以数据手册逐项对照。
- **接口**：沁恒的 USB 转串口芯片在开发板上几乎成了默认选项；CAN 收发器、隔离器、RS-485 有川土微、纳芯微、思瑞浦等；以太网 PHY 有裕太微等。
- **传感器与存储器**：霍尔与电流传感器有纳芯微等，MEMS 麦克风、加速度计、压力传感器也有国产厂商在做；NOR Flash 与 EEPROM 的国产化程度已经很高，兆易创新、普冉、聚辰等都有成熟产品。

**这里必须强调**：上面只是格局描述，**不代表任何一个具体型号可以无验证地替换另一个**。模拟器件尤其如此——运放、基准、电源芯片的噪声、温漂、环路特性差异，往往要实测才看得出来。**任何替代结论都要以数据手册对比加实测为准。**

## 测试工装与量产

产品装出来不等于能发货。产线上必须有一套**自动化的检测环节**，这就是产测治具（测试工装）的作用。常见的产测治具是一块**针床**：按产品的测试点排布弹簧探针，产品放上去、气缸压下，探针同时接触所有测试点。整套流程通常是：

**夹具上电 → 自动烧录固件 → 写入序列号/校准参数 → 自检程序跑一遍外设 → 测电压电流 → 测通信 → 判定 PASS/FAIL → 结果入库**

烧录和校准这一步尤其重要。**单片机内部 ADC 的基准、电流采样的零点、晶振的实际频偏，都存在批次差异**，所以量产通常在产测时把校正值写进每一台设备的参数区。这就是为什么很多设备刷了别人的固件会不准——校准数据是跟着单台设备走的。为什么量产必须有自动化测试？答案很朴素：

- **人工测不出来。** 很多故障是间歇性的、边界条件下的，要跑一段时间的负载才能暴露。
- **人工测太慢、也不一致。** 一个产品手工测十几分钟，一万台就是几千小时；不同的人判定标准不一样，漏检率无法统计，问题也没法追。

### 良率与失效分析

产线上最重要的两个指标是**直通率（一次测试通过的比例）**和**不良分布（集中在哪几个测试项）**，它们是研发和生产的共同语言：直通率突然下降，先查是不是换了料、换了批次、换了工艺参数；某一项长期有固定比例的不良，通常是设计问题（比如某个器件的容差余量不够），不是工艺问题。

**失效分析（FA）**的基本套路是：按不良现象分类 → 在实验室复现 → 定位到具体环节（来料、工艺、设计、软件）→ 找到根因 → 改设计或改工艺 → 用下一批数据验证改动是否有效。

对工程师来说，最有价值的能力不是"能修好这一块板"，而是**能从一批不良品里看出规律**。能说出"这批不良集中在焊接后 X 光下的某个位置，怀疑是钢网开孔导致锡量不足"的人，和只会说"这批坏了十几片"的人，在团队里的位置完全不同。

## 学习建议

1. **这一篇不用背，但要在做项目时对照着走一遍。** 真正让你记住这些的是"因为漏了坐标文件原点，整批器件贴歪"这种经历；**先学会整理 BOM** 则是本篇门槛最低、收益最高的一件事——把你的项目 BOM 按字段补全一次，你就明白为什么大公司要专门配 BOM 管理岗。
2. **国产替代先建"判断框架"，不要先背型号。** 型号和格局每年都在变（本篇提到的厂商都有可能变化），但评估维度这张表十年不会变。
3. **打样时就按量产的思路设计。** 封装不要贪小、能单面不双面、关键器件留替代位、测试点留出来。这些动作在打样阶段几乎不增加成本，在量产阶段能救命。
4. **面试前，把这一篇的表格过一遍。** "你怎么选型""你考虑过供货风险吗""国产替代要注意什么"——能答出评估维度而不是只报型号名，就是明显的加分项。
5. **诚实标注不确定。** 本篇涉及的价格、交期、型号兼容程度都随市场变化，**任何结论在下单前都要以厂商的最新数据手册和正式供货文件为准**。养成"先查再下结论"的习惯，比记住任何具体数字都重要。

## 小节总结

打样和量产的区别不是数量，而是改一版的代价。打样时随手做的决定，量产时会变成钢网费、治具费和认证费。**把量产意识提前到设计阶段，是硬件工程师最值钱的一种习惯。** 生产文件是一套完整的东西，Gerber 只是其中一份——原点统一、版本统一、位号与料号关系清晰，能避免绝大多数低级但致命的生产事故。BOM 不是表格，是研发和供应链之间唯一的接口，**物料编码与具体型号解耦，是它能不能长期用下去的分水岭。**

成本的大头在"设计"而不在"谈判"：减器件、减层数、缩面积的降本效果，远大于压供应商的价格。供货和生命周期则是选型时就要考虑的因素——**"先看供货再选型"不是保守，是工程上的基本素养**。

国产替代在这两年从选项变成了必备预案。它的核心判断是：**引脚兼容不等于软件兼容**。替代要评估引脚、电气、外设行为、勘误表、工具链、生态、长期供货和认证八个维度，真实成本是"重新验证一遍"，而不是"换一个型号"。便宜一点不值得换，供货更稳才值得。

最后，产品能不能发货由产测决定。产测治具、自动烧录与校准、良率统计、失效分析，这一整套东西看起来与"电路设计"无关，但它们才是**把图纸变成商品**的那一段路。
