# 2.3 算法

PID控制几乎是所有电控项目里都绕不开的算法，常被调侃"一瓶酒一包烟，一环PID调一天"。但电控中的"算法"远不止PID。广义上，算法是针对特定问题设计的一套计算步骤。在嵌入式场景中，它可以是一段滤波公式、一个状态转移逻辑、一套运动学解算流程，甚至是一种数据校验方法。选择合适的算法，往往能用很小的代码量解决靠硬件或蛮力调参难以解决的问题。

## 3.1 常见算法分类

电控中的算法种类很多，按用途大致可以分为以下几个大类：

| 类别 | 常用算法 |
|------|----------|
| 控制算法 | PID（位置式/增量式/串级）、前馈补偿、斜坡函数、死区控制 |
| 滤波算法 | 卡尔曼滤波、互补滤波、滑动均值滤波、中值滤波、低通滤波、指数加权移动平均 |
| 运动规划 | 梯形速度曲线、S曲线、贝塞尔曲线 |
| 运动学解算 | 底盘正逆解算、阿克曼模型、机械臂DH解算 |
| 电机控制 | FOC（磁场定向控制）、六步换相、SVPWM、死区补偿 |
| 传感器处理 | 编码器四倍频与测速、ADC多通道采样与校准、传感器数据标定 |
| 状态管理 | 有限状态机（FSM）、层次状态机（HSM） |
| 数据处理 | CRC校验、数据帧解析与粘包处理、标度变换 |

## 3.2 控制算法

控制算法是电控的核心，决定了系统能不能稳、准、快地达到目标状态。

### PID

PID是电控算法的入门必修课，也是工程中应用最广泛的基础控制算法。它的核心思路是根据目标值和实际值之间的误差，通过比例（P）、积分（I）、微分（D）三个环节来计算控制量，让系统尽快达到目标状态并保持稳定。

PID有几种常见的形式。位置式PID直接输出控制量的绝对值，适用于大多数基础控制场景。增量式PID输出的是控制量的变化量，天然具有抗积分饱和的能力，在电机控制中用得更多。串级PID则是在外环套内环，用两层PID分别控制不同变量，比如外环控制位置、内环控制速度，两层协同工作，控制效果比单环好很多。

PID调参是很多人的噩梦，但调参的关键不在于反复试数，而在于理解每个参数对应的物理意义。P决定响应速度，I用来消除稳态误差，D用来抑制超调和振荡。调参的基本顺序是：先把P调到系统能跟上目标值，再加I消除静差，最后加D平滑过渡。大多数场景按这个步骤来，都能调出一个可用的效果。

### 前馈补偿

前馈补偿不是一种独立的控制算法，而是和PID配合使用的策略。它的核心思路是"提前预判"——根据已知的模型或经验，直接给系统一个基础输出量，PID只负责修正偏差部分。比如电机控制中，如果知道匀速运行时需要固定的占空比，那就把这部分作为前馈直接输出，PID只需要处理加速、减速和扰动带来的误差。前馈用得好，可以显著减少PID的调节负担，响应速度也会更快。

### 斜坡函数

斜坡函数（Ramp）本质上是信号处理工具，而不是控制算法。它的作用是让一个突变的目标值变成平滑的线性过渡，避免阶跃信号直接冲击系统导致剧烈震荡。比如电机从0 rpm加速到1000 rpm，如果直接把目标值拍上去，系统会产生很大的超调；但如果用斜坡函数让目标值在一定时间内匀速上升，电机就会平稳加速，机械结构也不会受到冲击。斜坡函数在运动控制中非常常用，实现简单，效果明显。

### 死区控制

死区控制是指当误差小于一定阈值时，控制器不输出调节量，让系统保持当前状态不动。这看起来好像是"故意不管了"，但其实在很多场景下非常有用。比如电机定位时，如果误差已经小到可以忽略的范围，PID还在反复调节，就会导致电机频繁抖动。加一个死区之后，系统在误差够小时自动"收手"，既节省了能量，也避免了不必要的机械磨损。死区阈值需要根据实际精度要求来设定，太大会影响控制精度，太小则起不到效果。

## 3.3 滤波算法

传感器采集到的数据几乎不可能是完美干净的，总会夹带各种噪声。滤波算法的作用就是从带噪声的原始数据中提取出尽可能接近真实值的信号。不同的滤波算法适用于不同的噪声类型和应用场景，选对了事半功倍，选错了可能适得其反。

### 滑动均值滤波

滑动均值滤波是最简单、最容易实现的滤波方法。做法是维护一个固定长度的数据窗口，每次采样新数据时，把窗口里最老的数据丢掉、新数据加进来，然后取窗口内所有数据的平均值作为输出。它能有效抑制随机噪声，让输出曲线变得平滑。缺点是存在延迟，窗口越大平滑效果越好但延迟也越大，而且对突变信号的响应比较迟钝。适合用在ADC采样、传感器数据读取等信号变化相对缓慢的场景。

### 中值滤波

中值滤波和滑动均值类似，区别在于它取的是窗口内数据的中间值，而不是平均值。这个看似微小的差别带来了一个非常实用的特性：中值滤波对脉冲干扰（突刺噪声）的抑制效果特别好。如果某一次采样突然出现一个异常大或异常小的值，滑动均值会把这个异常值"摊"到结果里，但中值滤波会直接把它排到两端忽略掉。非常适合用在超声波测距、红外测距等容易出现偶发跳变的传感器上。

### 低通滤波

低通滤波的思路是只让低频信号通过，把高频噪声滤掉。最简单的实现方式是一阶RC低通滤波的数字版本：`输出 = 上次输出 × (1 - α) + 本次采样 × α`。α越小滤波越强、延迟越大，α越大越接近原始信号。它的计算量极小，适合资源紧张的场合，在传感器数据平滑、姿态解算中都非常常见。

### 指数加权移动平均（EWMA）

EWMA的原理和低通滤波非常接近，本质上就是对最近的数据赋予更高的权重、对历史数据的权重指数衰减。它的优点是不需要维护一个数据窗口，只需要保存上一次的输出值和一个权重系数，内存占用极小，计算也很快。适合用在实时性要求高、存储空间有限的场景，比如嵌入式设备上的数据趋势追踪和实时平滑。

### 互补滤波

互补滤波用于融合两个特性互补的传感器数据。最经典的例子是姿态解算中的加速度计和陀螺仪：加速度计长期稳定但短期噪声大，陀螺仪短期精确但长期会漂移。互补滤波的做法是给两者各分配一个权重，短期信任陀螺仪、长期信任加速度计，用一个简单的加权公式就能把两者融合成一个既不抖也不漂的结果。实现非常简单，只需要一个公式，计算量极小，非常适合资源受限但又需要姿态数据的场合。

### 卡尔曼滤波

卡尔曼滤波是一种基于概率模型的最优估计算法，理论上能在当前测量条件下给出最接近真实值的估计结果。它不仅仅是"滤掉噪声"，更重要的是能根据系统的运动模型和传感器的噪声特性，自动判断应该更相信模型预测还是更相信实际测量，并动态调整两者的权重。

基本卡尔曼滤波适用于线性系统，实际中很多系统是非线性的，这时候需要用扩展卡尔曼滤波（EKF）。EKF在IMU姿态解算、多传感器融合、机器人定位等场景中应用非常广泛。卡尔曼滤波的学习门槛相对较高，需要理解状态空间、协方差矩阵、预测—更新循环等概念，但它是非常值得深入掌握的算法之一，在工程中的价值极高。

## 3.4 运动规划

运动规划解决的是"怎么从A到B"的问题，但不是简单地直接冲过去，而是要规划出一条速度平稳、加速度连续、对机械结构友好的运动轨迹。

### 梯形速度曲线

梯形速度曲线是最简单也最常用的运动规划方法。整个运动过程分为三段：匀加速、匀速、匀减速，速度—时间图画出来是一个梯形。它的优点是实现简单、计算量小、容易调参；缺点是加速度在三段交界处存在突变，会产生冲击和振动。对于精度和平滑性要求不高的场景（比如普通小车的直线运动），梯形曲线已经完全够用。

### S曲线

S曲线是对梯形曲线的改进。它在加速段和减速段的起止位置增加了加加速度（Jerk）的过渡，让加速度本身也是平滑变化的，而不是突然跳变。速度—时间图画出来呈S形，因此得名。S曲线产生的冲击和振动比梯形曲线小很多，适合对平滑性要求较高的运动控制场景，比如精密定位、数控机床、3D打印机等。代价是计算复杂度比梯形曲线高，参数也更多。

### 贝塞尔曲线

贝塞尔曲线常用于路径规划中生成平滑的空间轨迹。通过设置若干个控制点，贝塞尔曲线可以生成一条平滑经过或趋近这些控制点的曲线。在机械臂轨迹规划、移动机器人路径规划、动画插值等场景中用得比较多。学习时重点理解控制点和曲线形状之间的关系，以及如何把生成的路径点转化为实际的电机控制指令。

## 3.5 运动学解算

运动学解算是机器人和移动平台的基础，它解决的核心问题是：底盘或关节怎么动，才能让整个系统按照预期的方向和速度运动。

### 差速底盘解算

差速底盘是最简单的移动平台结构，左右各一个驱动轮，通过两个轮子的速度差来实现转向。正运动学是已知左右轮速，求底盘的线速度和角速度；逆运动学是已知期望的线速度和角速度，反推左右轮应该各转多快。公式不复杂，但一定要搞清楚轮距、轮径这些物理参数和公式里变量的对应关系。

### 麦轮底盘解算

麦克纳姆轮底盘可以实现全向移动（前后左右平移加旋转），比差速底盘自由度更高。它的逆运动学本质上是把底盘期望的三个自由度（x方向速度、y方向速度、旋转角速度）分解到四个轮子上。公式网上很容易找到，关键是理解每个轮子的安装方向和辊子角度对速度分解的影响。

### 阿克曼模型

阿克曼转向是汽车和类汽车小车的标准转向方式。它的特点是前轮转向、后轮驱动，左右前轮的转角不一样，以保证所有轮子的瞬心在同一条直线上。阿克曼模型的运动学公式需要考虑轴距、前后轮距、转向角之间的几何关系。如果你的项目用的是类汽车结构的底盘，就需要掌握这个模型。

### 机械臂DH解算

机械臂的运动学解算相对更复杂，通常用DH参数法来描述每个关节的几何关系。正运动学是已知每个关节角度，通过齐次变换矩阵逐级相乘，计算末端执行器的位置和姿态。逆运动学则是已知末端位置，反推每个关节应该转到什么角度，通常比正运动学难很多，因为可能存在多组解甚至无解的情况。如果后续方向涉及机械臂或多关节系统，这部分需要专门深入学习。

## 3.6 电机控制算法

电机控制是电控方向最核心的应用场景之一。不同类型的电机需要不同的驱动和控制方式，这里列出几个最常见的算法。

### 六步换相

六步换相是无刷直流电机（BLDC）最经典的驱动方式。它把电气周期分成六个阶段，每个阶段导通两相、关断一相，按固定顺序依次切换。实现简单、成本低，但电流波形不够平滑，转矩脉动较大。对于不需要极致平顺性的场景（比如风扇、水泵、简单的电动车驱动），六步换相完全够用。

### FOC（磁场定向控制）

FOC是目前永磁同步电机（PMSM）和高性能BLDC控制的主流方案。它的核心思想是通过Clark变换和Park变换，把三相交流电流转换到一个随转子旋转的坐标系里，在这个坐标系下分别控制电流的力矩分量和磁场分量，实现精确的转矩控制。FOC的电流波形接近正弦，转矩脉动小、效率高、运行噪音低，但实现复杂度也高，需要同时掌握控制算法、坐标变换、电流采样、位置检测等多个环节。FOC是电机控制方向进阶的核心内容，也是很多岗位的硬性要求。

### SVPWM

空间矢量脉宽调制（SVPWM）是FOC控制中逆变器驱动环节常用的调制方式。相比传统的SPWM，SVPWM能更充分地利用母线电压，电压利用率提高约15%，谐波也更小。学习SVPWM需要理解空间电压矢量、扇区判断、矢量作用时间计算等概念，通常和FOC一起作为配套内容学习。

### 死区补偿

在使用H桥或三相逆变器驱动电机时，上下桥臂之间必须留有死区时间，防止直通短路。但死区时间会导致实际输出电压和理论值之间存在偏差，尤其在低速和小电流时影响明显，表现为电流波形畸变和转矩脉动。死区补偿算法的作用就是修正这个偏差，使实际输出更接近期望值。在FOC和高精度电机控制中，死区补偿是一个不可忽视的细节。

## 3.7 传感器处理

传感器是单片机获取外界信息的窗口，但传感器输出的原始数据往往不能直接使用，需要经过处理、转换和校准才能变成有意义的物理量。

### 编码器四倍频与测速

增量式编码器输出两路正交信号（A相和B相），常规做法是在A相上升沿计数，但如果同时利用A、B两相的上升沿和下降沿，分辨率可以提升到原来的四倍。这就是四倍频计数。在电机速度闭环控制中，四倍频能显著提高低速段的测量精度，是非常常见的处理手段。

测速方面常见两种方式：M法测速（单位时间内计脉冲数，适合中高速）和T法测速（测相邻脉冲之间的时间间隔，适合低速）。具体选哪种取决于电机的转速范围和对测速精度的要求。

### ADC多通道采样与校准

很多项目需要同时采集多路模拟信号（电压、电流、温度等），这时候就需要用到ADC的多通道扫描模式，通常配合DMA自动搬运数据，减少CPU占用。

ADC的原始采样值和实际物理量之间通常需要校准。最基本的校准是线性映射（量程转换），更精确的校准还需要考虑偏移误差、增益误差和非线性误差。可以通过已知标准值进行多点标定，再用拟合的方式得到校准公式。

### 传感器数据标定

很多传感器出厂时存在零漂和灵敏度偏差。比如加速度计的三个轴零点不一定在0g上，陀螺仪静止时也可能有一定的漂移速率。标定的过程就是通过已知的参考状态（比如静止放平、旋转特定角度）采集数据，计算出偏移量和比例系数，后续在程序中对原始数据进行修正。标定做得好不好，直接影响后续所有基于传感器数据的算法效果，尤其是姿态解算和运动控制，对传感器数据质量非常敏感。

## 3.8 状态管理

### 有限状态机（FSM）

有限状态机是一种非常实用的程序结构设计方法。核心思想是把系统所有可能的状态列出来，定义好每个状态下能接受什么输入、执行什么动作、跳转到什么状态。它让程序逻辑变得清晰可控，避免代码写成一团乱麻的if-else嵌套。

典型应用场景包括：设备运行流程管理（等待自检 → 就绪 → 运行 → 报错 → 停机）、通信协议处理（空闲 → 等待帧头 → 接收数据 → 校验 → 处理 → 回到空闲）、以及任何涉及多步骤、多模式切换的逻辑。

状态机不是一种高深的算法，但它是一种非常好的编程思维。养成用状态机来组织复杂逻辑的习惯，能让代码结构更清晰、更容易维护和调试，也更不容易出现状态混乱导致的bug。

### 层次状态机（HSM）

当系统状态变得非常多、层次关系复杂的时候，普通的FSM可能会出现大量重复的状态转移逻辑。层次状态机允许状态嵌套，子状态可以继承父状态的通用行为，只需要处理自己独有的逻辑。这种方式在复杂系统（比如多模式运行的设备、多层级的UI界面）中非常有用，能大幅减少冗余代码，提高可维护性。初学阶段了解它的存在即可，等到普通FSM不够用的时候再深入学习。

## 3.9 数据处理

### CRC校验

CRC（循环冗余校验）是通信中最常见的数据完整性检验方法之一。发送端根据数据内容用特定多项式计算出一个校验值附在数据末尾，接收端收到后用同样的算法重新计算并比较，不一致就说明传输过程中出了问题。常见的有CRC-8、CRC-16、CRC-32，选择哪种取决于协议要求和检错能力需求。学习CRC不需要深究背后的数学原理，重点是理解它的作用、会用查表法实现、知道怎么在协议里使用。

### 数据帧解析与粘包处理

在串口通信或网络通信中，经常需要按照约定的协议格式解析数据帧，比如帧头 + 数据长度 + 数据内容 + CRC校验这种常见结构。接收端需要逐字节判断当前处于帧的哪个位置，提取出有效数据。

粘包是指多个数据帧被连在一起一次性收到，接收端需要正确地把它们拆开。常见的处理方式包括帧头帧尾标记法、长度字段法、超时分帧法等。这部分内容在任何涉及数据通信的项目中都会遇到，是实现稳定数据传输的基本功。

### 标度变换

标度变换就是把传感器或ADC输出的原始数值转换成实际的物理量。比如ADC读出来的是一个0到4095的整数，你需要把它换算成0到3.3V的电压值；再比如电流传感器输出的电压，需要根据灵敏度系数转换成实际安培数。这个过程看起来简单，但在精度要求高的场合，需要考虑零漂补偿、增益校正、非线性补偿等因素。标度变换是工程中最基础也最频繁的数据处理操作之一。

## 3.10 进阶算法索引（选学）

以下内容不要求必须掌握，但了解它们的存在和适用场景，会让你在面对复杂问题时多一些解决思路。同时，这些内容也是从普通电控开发逐步走向算法岗、机器人岗、控制岗的重要进阶方向。

### 1. 观测与估计

| 算法 | 说明 | 典型应用 |
|------|------|----------|
| 状态观测器 | 根据可测输出估计不可直接测量的内部状态 | 电机控制中估计转子位置和速度 |
| 龙伯格观测器 | 经典线性状态观测器，通过误差反馈修正状态估计 | 线性系统状态估计 |
| 扩展卡尔曼滤波（EKF） | 对非线性系统进行一阶线性化后的状态估计 | IMU姿态解算、多传感器融合 |
| 无迹卡尔曼滤波（UKF） | 用采样点传播状态分布，避免显式线性化 | 高精度姿态估计、目标跟踪 |
| 粒子滤波 | 用大量随机粒子逼近状态概率分布 | 机器人定位、SLAM、目标跟踪 |
| 滑模观测器（SMO） | 鲁棒性强，对模型误差不敏感 | 无感FOC、电机状态估计 |

这一类算法解决的核心问题是"有些关键状态测不到，能不能根据现有信息估算出来"。比如无感电机控制中没有编码器，系统需要根据电流电压推算转子位置；姿态解算中无法直接测到姿态角，只能通过多传感器数据融合来估计。龙伯格观测器是理解状态估计的基础入门，EKF是工程中最常用的非线性估计方法，UKF和粒子滤波则适合更复杂的高精度场景。如果以后你想往电机控制、姿态估计、传感器融合方向深入，这一类算法会非常关键。

### 2. 现代控制与优化

| 算法 | 说明 | 典型应用 |
|------|------|----------|
| LQR | 线性二次最优控制，在性能和能耗之间寻找平衡 | 平衡车、无人机姿态控制 |
| LQG | LQR与卡尔曼滤波结合，处理带噪声的最优控制 | 有噪声系统的最优控制 |
| MPC（模型预测控制） | 利用系统模型进行滚动优化控制 | 路径跟踪、高性能控制 |
| 自适应控制 | 控制器参数随系统特性变化而自动调整 | 负载变化大的系统 |
| 鲁棒控制（H∞） | 在存在模型不确定性时保证稳定性和性能 | 高可靠控制系统 |
| 滑模控制（SMC） | 通过设计滑模面增强抗干扰能力 | 机器人控制、电机调速 |
| 模糊控制 | 不依赖精确模型，用模糊规则实现控制 | 难以建模的系统 |
| 最小二乘法 | 通过最小化误差平方和估计参数 | 标定、辨识、拟合 |
| 梯度下降 | 沿误差下降方向迭代优化参数 | 参数调优、机器学习基础 |
| 遗传算法 / 粒子群优化（PSO） | 不依赖梯度的全局优化方法 | PID整定、多参数优化 |

这一类算法比PID更强调系统模型、性能指标和全局最优。LQR适合线性系统的最优控制，LQG在LQR基础上引入卡尔曼滤波处理噪声，MPC则更适合多变量、有约束的复杂控制场景。滑模控制和鲁棒控制更强调在模型不准、存在干扰的情况下仍然保持系统稳定。模糊控制则适合那些难以建立精确数学模型但经验规则比较清晰的对象。最小二乘法、梯度下降、遗传算法、粒子群优化这些优化工具，在参数辨识、自动调参和系统优化里非常常见。整体来说，这一类算法是从"能控制"走向"控制得好"的关键跃迁点。

### 3. 信号处理

| 算法 | 说明 | 典型应用 |
|------|------|----------|
| FFT（快速傅里叶变换） | 将时域信号转换到频域分析 | 振动分析、故障检测、频谱显示 |
| STFT（短时傅里叶变换） | 分段进行频谱分析，兼顾时域和频域 | 语音处理、非平稳信号分析 |
| 小波变换 | 多分辨率时频分析方法 | 故障诊断、瞬态检测 |
| FIR滤波器 | 有限脉冲响应滤波器，相位线性、稳定性好 | 音频处理、精密滤波 |
| IIR滤波器 | 无限脉冲响应滤波器，效率高、阶数低 | 实时滤波、嵌入式信号处理 |
| 自相关 / 互相关 | 分析信号周期性和相似性 | 周期检测、时延估计、匹配 |
| PLL（锁相环） | 跟踪输入信号频率与相位 | 电网同步、解调、频率跟踪 |
| 陷波器 | 针对特定频率进行抑制 | 工频干扰消除、机械共振抑制 |

这一类算法主要解决"信号里到底有什么、怎么把有用成分提取出来"的问题。FFT是最基础的频域分析工具，能让你看到信号的频率组成；STFT和小波变换则适合频率成分会随时间变化的场景。FIR和IIR是两类主要的数字滤波器，FIR相位线性、稳定性好，IIR计算效率更高。陷波器在消除工频干扰或机械共振时非常实用，PLL在电网同步和通信解调中是核心组件。如果你以后接触电机故障诊断、振动分析、音频处理或者电能质量方向，这一类算法会是重点。

### 4. 参数辨识与系统辨识

| 算法 | 说明 | 典型应用 |
|------|------|----------|
| 最小二乘法 | 利用误差最小化进行参数拟合 | 传感器标定、参数估计 |
| 递推最小二乘（RLS） | 在线更新参数估计，适合实时场景 | 在线辨识、实时建模 |
| 系统辨识 | 根据输入输出数据建立系统模型 | 控制对象建模 |
| ARX / ARMAX模型 | 常见离散系统辨识模型 | 工业过程辨识 |
| 曲线拟合 | 根据样本数据构建函数关系 | 传感器标定、补偿函数生成 |
| 在线参数估计 | 系统运行过程中动态估计参数 | 时变系统、自适应控制 |

这一类算法解决的是"系统模型不知道、参数不准，怎么估出来"的问题。很多控制算法要想效果好，前提是你得知道系统大概长什么样，但现实里很多对象都没有现成的精确模型，这时就需要靠辨识算法去估计。比如电流传感器标定、电机参数估算、控制对象传递函数未知，都可能会用到这类方法。参数辨识往往决定了后续控制器能不能真正调好，是一个不显眼但很重要的方向。

### 5. 故障诊断与健康监测

| 算法 | 说明 | 典型应用 |
|------|------|----------|
| 残差法 | 利用模型输出与实际输出的偏差判断异常 | 控制系统故障检测 |
| 阈值检测 | 通过设定阈值识别异常状态 | 基础故障报警 |
| 卡方检测 | 基于统计量检测异常 | 传感器异常判断 |
| 频谱特征分析 | 利用频域特征识别故障 | 轴承故障、电机振动分析 |
| 异常检测 | 识别偏离正常模式的数据 | 设备监测、预测性维护 |
| 健康状态评估 | 综合多项指标判断设备健康程度 | 工业设备、电池状态评估 |

这一类算法解决的是"设备有没有坏、现在的状态是不是正常"的问题。最简单的是阈值检测，比如温度超限就报警；更进一步的是基于模型残差或频谱特征来识别具体的故障类型，比如轴承磨损、电机匝间短路等。在普通电控学习路线里这一块容易被忽略，但在工业控制、电机维护、电池管理系统等方向上非常重要。随着设备智能化程度的提高，故障预测和健康监测会越来越成为主流需求。

### 6. 编码与通信

| 算法 | 说明 | 典型应用 |
|------|------|----------|
| 哈夫曼编码 | 基于频率构建无损压缩编码 | 数据存储与传输优化 |
| Reed-Solomon | 前向纠错编码，支持部分数据损坏后恢复 | 通信抗干扰、二维码、存储纠错 |
| 卷积码 / Turbo码 / LDPC码 | 不同性能等级的信道编码方法 | 无线通信、深空通信、抗误码 |
| 协议状态机 | 管理通信协议的收发流程 | 串口协议、网络协议开发 |
| Base64 / Hex编码 | 将二进制数据转成文本格式传输 | 数据传输、调试输出 |

这一类算法主要解决"数据怎么更可靠、更高效地传输和解析"的问题。CRC、数据帧解析这些常用内容已经放在前面的常见算法里了，这里的内容更偏进阶和深入。Reed-Solomon在二维码、光盘、卫星通信中应用极广，理解它有助于明白为什么数据在部分损坏的情况下仍然能恢复。协议状态机在复杂通信协议开发中几乎是标配。Base64和Hex虽然简单，但在实际调试和协议封装中使用频率很高。如果你以后往通信、网络设备、嵌入式协议栈方向走，这部分内容值得深入。

### 7. 数值计算与快速求解

| 算法 | 说明 | 典型应用 |
|------|------|----------|
| 牛顿迭代法 | 迭代求解非线性方程 | 逆运动学、参数求解 |
| 二分法 | 简单稳定的数值求根方法 | 函数零点求解 |
| 线性插值 / 多项式插值 | 用离散点逼近连续函数 | 查表补偿、传感器校准 |
| 查表法 | 预先存储计算结果以提高运行速度 | 三角函数近似、控制补偿 |
| CORDIC | 高效求解三角函数和反三角函数 | 资源受限平台数学计算 |
| 矩阵分解 | 用于线性方程组求解和优化问题 | 控制计算、滤波算法 |

这一类算法平时不一定被单独称作"电控算法"，但在嵌入式开发里非常实用。很多公式理论上能算，但单片机算得太慢或者浮点资源有限，这时候就需要查表法、插值法、CORDIC这类方法来加速。比如FOC控制中需要大量三角函数运算，用CORDIC或查表替代标准math库可以显著提升执行速度。机械臂逆运动学求解、卡尔曼滤波中的矩阵运算，本质上也都离不开数值计算方法。这部分内容往往不显眼，但真正做复杂系统时会频繁遇到，是工程落地中不可忽视的一环。

## 学习建议

进阶算法索引不要求全部掌握，更不建议一上来就全部投入学习。更合理的方式是先把常见算法部分打牢，遇到基础算法解决不了的问题时，再根据方向有针对性地深入。

- 做电机控制方向，重点看观测与估计、现代控制、信号处理相关内容。
- 做机器人和导航方向，重点看路径规划、定位与建图、参数辨识相关内容。
- 做工业控制和设备监测方向，重点看故障诊断、系统辨识、鲁棒控制相关内容。
- 做通信和协议方向，重点看编码与通信、协议状态机相关内容。
- 对前沿方向感兴趣，可以了解智能控制和TinyML相关内容。

算法这条路没有终点，重要的是先知道有哪些工具可以用，遇到问题时知道往哪个方向去找答案。

需要注意的是，算法覆盖面非常广，目前也没有一套真正适合所有电控同学"从头看到尾就能学会"的通用课程。很多算法本身就偏理论，最终还是要靠仿真、代码实现和项目应用来真正理解。所以在学习算法时，不必追求面面俱到，更建议采用"用到什么学什么"的方式：项目需要哪类算法，就去重点补哪一类。这样效率更高，也更容易把理论和实际结合起来。

## 小节总结

算法是电控开发中从"能跑起来"走向"跑得更好"的关键一环。它并不只等于PID，而是涵盖了控制、滤波、运动学、状态管理、数据处理等多个方面。很多时候，系统效果不好并不是硬件不行，而是算法和模型没有选对。

对于电控同学来说，最重要的不是一开始掌握多少高级算法，而是先建立基本的算法意识：遇到问题时，知道可以从控制、估计、滤波、补偿、规划这些角度去思考。只要把常见算法用熟，在项目中不断积累，后续再接触更复杂的进阶算法时就会顺畅很多。
