# 嵌入式学习指南

> 作者：VOW

## 前言

作者曾苦于学校没有完整的电控培训体系，直到现在校内也没有可供参考的公开学习路线。于是决定整理这份指南，供大家参考。

后来发现，被同样问题困扰的人远不止校内的同学：**转行想入行的人不知道该学什么，在校生不知道为什么学，在职的人不知道自己缺什么**。行业里技术资料很多，但缺少一份把"这个行业有哪些位置、每个位置要什么、该怎么一步步走过去"讲清楚的路线图。

于是有了现在这份重写后的版本。它不再局限于某个学校、某个战队，而是试图覆盖嵌入式行业的主要岗位和技术方向，让不同起点的人都能找到自己的入口。

本文由多人协作撰写，内容力求覆盖嵌入式核心技能，但受限于作者水平与经验，难免有疏漏与不足，欢迎批评指正。

## 这份教程的正确用法

**嵌入式不是靠"读"学会的，是靠"做"学会的。**

这份教程不是一本需要从头读到尾的教材，而是一张**可以按需查阅的地图 + 一条可以照着走的路线**。正确的使用方式是：**先动手做一个东西，卡在哪里，翻到哪一篇。**

每一篇开头都有四行信息，是你的导航仪：

> **前置知识**：读这一篇之前你最好已经会什么
> **掌握标准**：学完这一篇你应该能做什么（可自检）
> **对应岗位**：这一篇在哪些岗位用得上
> **练手建议**：把知识变成产出的一件具体的事

详细的阅读方法、各章难度、装备采购清单和常见学习误区，见 **[0.3 怎么用这份教程](docs/00-导读/03-怎么用这份教程.md)**。

## 使用说明

嵌入式各方向的基础层高度共用，所以你不需要现在就决定一辈子的方向。更现实的做法是：**先把公共基础打了，同时在项目里试不同的分支，方向感是做出来的，不是想出来的。**

也不必被这份文档的篇幅吓到。每个人走的路都不一样，找到适合自己的节奏，持续积累，终会有所成。

欢迎通过 Issue / PR 提出修改建议或补充内容。
